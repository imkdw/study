## 간단한 구현

- 읽기 스트림의 기본 highWatermark 64kb 단위로 데이터를 분할해서 서버가 받고 저장함
- 큰 영상도 적은 메모리 사용률로 다운로드가 가능함
- 단 아래 코드에는 백프레셔 제어 & 드레이닝 과정이 없어서 수신자의 네트워크 대역폭 등이 원활하지 않으면 문제가 발생함
- 디스크에서 데이터를 가져오고 해당 데이터를 다시 계속해서 밀어넣는데 결국 받지 못한건 OS 커널이 아닌 Node.js 런타임에 큐 형태로 계속 적재됨
- 이후에 메모리가 꽉 차버리면 OOM이 발생해버림. 이는 읽고 쏘는 속도의 불균형이 만든 병목현상임. 이를 꼭 제어해야함

### 서버

```ts
import net from "node:net";
import fs from "node:fs/promises";

const PORT = 6060;
const HOST = "::1";

const uploaderServer = net.createServer();

uploaderServer.on("connection", async (clientSocket) => {
  console.log(`신규 클라 접속 : ${clientSocket.remoteAddress}:${clientSocket.remotePort}`);
  const destFileHandle = await fs.open("./storage/uploaded-video.mp4", "w");
  const fileWriteStream = destFileHandle.createWriteStream();
  let recivedBytes = 0;

  clientSocket.on("data", (chunk) => {
    recivedBytes += chunk.length;
    process.stdout.write(`\r[서버 수신 중] ... ${(recivedBytes / (1024 * 1024)).toFixed(2)} MB 저장완료`);
    fileWriteStream.write(chunk);
  });

  clientSocket.on("end", async () => {
    console.log(`\n모든 데이터 수신 완료. 파일이 성공적으로 저장됨`);
    await destFileHandle.close();
  });
});

uploaderServer.listen(PORT, HOST, () => {
  console.log(`서버 시작 : ${HOST}:${PORT}`);
});
```

## 백프레셔 제어하기

- pause, resume 메서드와 drain 이벤트를 통해서 위 같은 백프레셔 문제 제어가 가능함
- 하지만 아래같은 코드의 경우 매번 사람이 제어를 해야하기때문에 휴먼에러가 발생할 수 있음
- pipe를 사용하면 더 안전하고 세련된 코드 작성이 가능함

### 서버

```ts
import net from "node:net";
import fs from "node:fs/promises";
import type { WriteStream } from "node:fs";

const PORT = 6060;
const HOST = "::1";

const uploaderServer = net.createServer();

uploaderServer.on("connection", async (clientSocket) => {
  console.log(`신규 클라 접속 : ${clientSocket.remoteAddress}:${clientSocket.remotePort}`);

  /**
   * 다중 접속 환경에서 메모리 오염을 막기 위해서 클로저 내부에 파일 핸들과 파이프 변수를 선언해놓음
   */
  let destFileHandle: fs.FileHandle | null = null;
  let fileWriteStream: WriteStream | null = null;
  let recivedBytes = 0;

  clientSocket.on("data", async (chunk) => {
    /**
     * 아직 쓰기 작업을 위한 디스크 접근 권한이 없다면 소켓 수신을 정지해서 데이터가 더 안들어오게 막음
     */
    if (!destFileHandle) {
      clientSocket.pause();

      destFileHandle = await fs.open("./storage/uploaded-video.mp4", "w");
      fileWriteStream = destFileHandle.createWriteStream();

      fileWriteStream.write(chunk);
      recivedBytes += chunk.length;

      process.stdout.clearLine(0);
      process.stdout.cursorTo(0);
      process.stdout.write(`\r[서버 수신 중] ... ${(recivedBytes / (1024 * 1024)).toFixed(2)} MB 저장완료`);

      /**
       * 디스크 쓰기 버퍼가 비워지면 다시 소켓 수신을 재개함
       */
      fileWriteStream.on("drain", () => clientSocket.resume());

      /**
       * 데이터를 받기 위한 모든 준비가 끝나면 다시 소켓 수신을 재개함
       */
      clientSocket.resume();
    } else {
      /**
       * 이미 디스크 쓰기 작업이 가능하다면 바로 데이터 받아서 처리함
       */
      recivedBytes += chunk.length;
      process.stdout.clearLine(0);
      process.stdout.cursorTo(0);
      process.stdout.write(`\r[서버 수신 중] ... ${(recivedBytes / (1024 * 1024)).toFixed(2)} MB 저장완료`);

      /**
       * 버퍼가 꽉 차서 쓰기 작업이 불가능하면 잠깐 소켓 수신을 멈춤 (백프레셔)
       */
      if (!fileWriteStream?.write(chunk)) {
        clientSocket.pause();
      }
    }

    clientSocket.on("end", async () => {
      if (destFileHandle) {
        await destFileHandle.close();

        /**
         * 과거 쓰래기 값을 참조하지 않도록 변수 초기화
         */
        destFileHandle = null;
        fileWriteStream = null;
      }

      console.log(`데이터 수신 끝. 통신 종료`);
    });
  });
});

uploaderServer.listen(PORT, HOST, () => {
  console.log(`서버 시작 : ${HOST}:${PORT}`);
});
```

## pipe를 활용한 리팩토링

- pipe는 백프레셔 제어를 알아서 해줌
- 또한 TCP 단편화를 대비해서 별도의 구분자를 통해서 헤더를 파싱하고 버퍼링하는게 중요함

### 서버

```ts
import net from "node:net";
import fs, { WriteStream } from "node:fs";
import path from "node:path";

const PORT = 6060;
const HOST = "::1";

function getTime() {
  return new Date().toLocaleTimeString("ko-KR");
}

const uploaderServer = net.createServer();

uploaderServer.on("connection", (clientSocket) => {
  console.log(`[${getTime()}] 새로운 클라 접속함. IP: ${clientSocket.remoteAddress}:${clientSocket.remotePort}`);

  let fileWriteStream: WriteStream;
  let receivedBytes = 0;

  /**
   * TCP Fragmentation에 대비해서 데이터 누적을 위한 빈 버퍼를 하나 만들어놓음
   */
  let headerBuffer = Buffer.alloc(0);

  const delimiter = "-----BOF-----";

  const onDataForHeader = (chunk: Buffer) => {
    headerBuffer = Buffer.concat([headerBuffer, chunk]);

    const delimiterIndex = headerBuffer.indexOf(delimiter);

    if (delimiterIndex === -1) {
      /**
       * OOM 방어를 위한 로직으로 1024 바이트가 넘도록 구분자가 없다면 악성 요청으로 간주해서 연결 끊어버림
       * 헤더와 파일 데이터가 한 청크로 합쳐져 올 수 있으므로 구분자를 못 찾았을 때만 검사함
       */
      if (headerBuffer.length > 1024) {
        console.log(`[${getTime()}] 악성 데이터 감지함. 헤더 구분자 없음. 소켓 종료함`);
        clientSocket.destroy();
      }
      return;
    }

    console.log(`\n[${getTime()}] '-----BOF-----' 구분자 발견함. 헤더 파싱 시작`);

    /**
     * 버퍼의 맨 처음부터 구분자 시작 위치 전까지 잘라내면 파일명이 나옴
     * 클라가 보낸 값에 경로가 섞여있어도 storage 밖으로 못나가게 순수 파일명만 남김
     */
    const fileName = path.basename(headerBuffer.subarray(0, delimiterIndex).toString("utf-8"));
    console.log(`[${getTime()}] 동적 파일명 파싱 성공: 파일명은 ${fileName} 입니다`);

    /**
     * 이제 헤더 안찾아도 되니까 현재 리스너는 소켓에서 제거함 (해제시킴)
     */
    clientSocket.off("data", onDataForHeader);

    /**
     * 구분자 이후부터 버퍼 끝까지 날라내서 헤더 뒤에 딸려온 진짜 파일 데이터 파편을 추출함
     */
    const remainingData = headerBuffer.subarray(delimiterIndex + delimiter.length);

    /**
     * 추출한 동적 파일명 폴더 경로에 합성해서 쓰기 스트림 만듦
     */
    fileWriteStream = fs.createWriteStream(`./storage/${fileName}`);

    /**
     * 딸려온 파일 데이터 파편이 있으면 쓰기 파이프에 밀어넣어놓음
     */
    if (remainingData.length > 0) {
      fileWriteStream.write(remainingData);
      receivedBytes += remainingData.length;
    }

    process.stdout.write(`[서버 수신 중] ... ${(receivedBytes / (1024 * 1024)).toFixed(2)} MB 저장완료`);

    /**
     * 남은 소켓 데이터를 쓰기 스트림으로 파이프 연결함 (서버쪽 백프레셔 자동화 적용)
     */
    clientSocket.pipe(fileWriteStream);

    /**
     * 첫 헤더 이후에 연달아서 들어오는 후속 청크들을 처리함
     */
    clientSocket.on("data", (subsequentChunk) => {
      receivedBytes += subsequentChunk.length;
      process.stdout.clearLine(0);
      process.stdout.cursorTo(0);
      process.stdout.write(`[서버 수신 중] ... ${(receivedBytes / (1024 * 1024)).toFixed(2)} MB 저장완료`);
    });

    fileWriteStream.on("finish", () => {
      console.log(`\n[${getTime()}] ${fileName} 파일 수신 및 저장 완료. 통신 종료함`);
    });
  };

  clientSocket.on("data", onDataForHeader);

  clientSocket.on("error", (err) => {
    console.log(`[${getTime()}] 에러발생 : ${err.message}`);
  });
});

uploaderServer.listen(PORT, HOST, () => {
  console.log(`[${getTime()}] 서버 실행중 (${HOST}:${PORT})`);
});
```

```ts
import net from "node:net";
import fs from "node:fs";
import path from "node:path";

/**
 * 프로세스 실행 시 터미널에서 넘겨받은 인자 배열 중 3번째 값을 추출함
 */
const targetFilePath = process.argv[2];

if (!targetFilePath) {
  console.log(`[에러] 업로드할 파일 경로 입력해`);
  console.log(`[사용법] node upload_client.ts <파일주소>`);
  process.exit(1);
}

const PORT = 6060;
const HOST = "::1";

function getTime() {
  return new Date().toLocaleTimeString("ko-KR");
}

const uploaderClient = net.createConnection(
  {
    port: PORT,
    host: HOST,
  },
  async () => {
    console.log(`[${getTime()}] 서버랑 연결 성공함`);

    /**
     * 터미널로 입력받은 전체 경로에서 순수 파일명 + 확장자만 추출함
     */
    const fileName = path.basename(targetFilePath);

    /**
     * 서버와 클라이언트칸 약속된 구분자를 정하고 이를 사용해서 구분을 진행함
     * 이 때 일반적으로 파일에서는 안나올법한 문자열을 사용해야함
     * 아래 BOF는 Beginning Of File의 약자임
     */
    const header = `${fileName}-----BOF-----`;
    uploaderClient.write(header);

    const fileReadStream = fs.createReadStream(targetFilePath);
    let uploadedBytes = 0;

    fileReadStream.on("data", (chunk) => {
      uploadedBytes += chunk.length;
      process.stdout.clearLine(0);
      process.stdout.cursorTo(0);
      process.stdout.write(`\r[클라 전송 중] ... ${(uploadedBytes / (1024 * 1024)).toFixed(2)} MB 전송완료`);
    });

    fileReadStream.on("end", () => {
      console.log(`\n[${getTime()}] 파이프라인을 통한 파일 전체 전송 성공`);
    });

    fileReadStream.on("error", (err) => {
      console.log(`[${getTime()}] 에러 발생 : ${err.message}`);
    });

    /**
     * 기존 백프레셔 제어 & 드레이닝을 자동화하는 파이프를 연결함
     *
     * pipeline을 사용하면 중간에 발생하는 데이터 유실 등을 모두 처리해주지만 여기서는 pipe를 사용함
     * 여기서는 N개의 스트림이 엮인게 아닌 서버 + 클라이언트 오직 2개만 존재함
     */
    fileReadStream.pipe(uploaderClient);
  },
);

uploaderClient.on("connect", () => {
  console.log(`서버 접속 완료 : ${HOST}:${PORT}`);
});
```
