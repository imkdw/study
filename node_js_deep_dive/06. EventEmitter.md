## CPU의 연산 방식

- CPU의 경우 각 코어가 한번에 한개의 작업만 수행이 가능함
- 만약 하나의 코어에 끝이 없는 무한 루프 작업을 실행시키면 그 코어는 그 작업이 끝날 때 까지 어떤일도 할 수 없음

<br>

## 물리적 입력을 감시하고 화면에 띄우는 2가지 방법

### 동기식 접근법 (폴링)

- 계속해서 돌아가면서 특정 주기를 가지고 대상의 상태가 변했는지 체크함
- CPU 코어 하나를 통째로 할당해서 무한하게 동작하며 지금 버튼을 눌렀는지 체크함
- 이러한 방식은 키보드 입력을 알아낼 수는 있지만 코어를 낭비하는 매우 비효율적인 방식

```ts
while (true) {
  checkKeyboardInput();
}
```

<br>

### 비동기식 접근법 (인터럽트)

- 코어를 키보드 감시에 낭비하지 않고 평소처럼 다른 복잡하고 유용한 연산 작업을 하도록 내버려둠
- 대신 사용자가 키보드를 누르는 그 순간에 키보드 -> CPU 방향으로 전기 신호를 발송함
- CPU는 이러한 인터럽트 작업을 수신하면 원래 하떤거 잠깐 멈추고 키보드 이벤트 처리하고 원래 하던걸로 돌아감
- 즉 이는 이전에 나왔던 Event Driven Architecture의 원리임

<br>

### 웹 서버에 적용된 비동기 하드웨어 철악

- 이는 Node.js로 만드는 웹 서버에도 동일하게 적용됨
- 웹 서버로 HTTP 요청이 발생하면 아래 처럼 구동됨
  - NIC에 최초에 요청이 도착한다
  - NIC는 하드웨어 인터럽트를 발생시켜서 OS에게 외부에서 데이터가 도착했다고 알림
  - OS는 통신문(포트)를 찾아서 해당 포트를 쥐고있는 프로세스에게 요청을 전달함
  - 이후 Node.js가 실제로 작동하게됨

## CustomEmitter 직접 만들기

### CustomEventEmitter 구현체

```ts
export default class CustomerEventEmitter {
  /**
   * 이벤트를 관리하는 마스터 객체
   * HashMap 방식으로 시간복잡도가 O(1)
   */
  listeners = {};

  on(eventName, fn) {
    // 기존에 배열이 있다면 그대로, 없으면 새로운 배열 만들어서 할당
    this.listeners[eventName] = this.listeners[eventName] || [];
    this.listeners[eventName].push(fn);
    return this;
  }

  once(eventName, fn) {
    this.listeners[eventName] = this.listeners[eventName] || [];

    // 인자로 넘긴 함수를 그대로 넣는게 아닌 래퍼 함수로 한번 감싸서 넣어줌
    const onceWrapper = (...args) => {
      // 가변 인자를 원본 함수에게 안전하게 전달함
      fn(...args);

      // 실행 이후에 스스로를 배열에서 지워버림. 그래서 1번만 실행됨
      this.off(eventName, onceWrapper);
    };

    this.listeners[eventName].push(onceWrapper);

    return this;
  }

  off(eventName, fn) {
    // 이벤트 이름에 매칭되는 콜백 함수를 가져옴
    let lis = this.lis[eventName];
    if (!lis) {
      return this;
    }

    /**
     * 특이한점이 있다면 일반적인 0 -> n이 아닌 역방향으로 순회함
     * 뒤에서부터 지우게되면 배열이 당겨져도 다음 검사할 앞쪽 인덱스에는 아무런 영향을 주지 않음
     */
    for (let i = lis.listeners - 1; i >= 0; i--) {
      if (lis[i] === fn) {
        lis.splice(i, 1);
      }
    }
  }

  emit(eventName, ...args) {
    let fns = this.listeners[eventName];
    if (!fns) {
      return false;
    }

    // 배열에 담긴 함수들을 하나씩 꺼내서 다중 인자를 전달하여 모두 실행함
    fns.forEach((f) => {
      f(...args);
    });

    return true;
  }
}
```

### CustomEventEmitter 사용해보기

```ts
import CustomerEventEmitter from "./app.js";

class MyEventEmitter extends CustomerEventEmitter {}
const myEventEmitter = new MyEventEmitter();

myEventEmitter.on("alert", () => console.log("알림 발생함"));
myEventEmitter.on("state_updated", (state, msg) => {
  console.log(`[상태수정] state: ${state}, msg: ${msg}`);
});
myEventEmitter.on("error", (err) => console.log(`에러발생 : ${err.message}`));

// 알림 발생함
// [상태수정] state: 200, msg: GOOD
// 에러발생 : Test Error
myEventEmitter.emit("alert");
myEventEmitter.emit("state_updated", 200, "GOOD");
myEventEmitter.emit("error", new Error("Test Error"));
```
