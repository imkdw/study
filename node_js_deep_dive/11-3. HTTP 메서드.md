## 멱등성(Idempotency)

- 어떤 연산이나 함수를 한번 또는 여러번 실행했을때 대상 시스템에 미치는 영향이 동일하면 멱등성을 유지한다고 부름
- 클라이언트가 서버에게 같은 요청을 여러번 보냈을 때 첫 번째 요청만 서버의 DB나 상태를 변화시키고 나머지는 영향이 없다면 이는 멱등성을 가진다고 평가함

<br>

### HTTP 메서드의 완벽한 규명 : Safe & Idempotent

- safe의 의미는 해당 메서드를 호출해도 서버의 상태나 디비가 절대 변경되지 않는 완벽한 읽기전용(read-only)를 의미함
- 즉 safe는 상태를 일절 건드리지 않는다는 의미임
