Gemini API로 배우는 LLM 실전 코스

Anthropic 공식 코스(anthropics/courses)를 기반으로 재구성한 학습 자료입니다. 모든 실습 코드는 TypeScript + @google/genai SDK(Gemini API)로 작성되어 있습니다.

실습 환경 준비

모든 예제는 Node.js + TypeScript로 실행합니다.

npm install @google/genai
npm install -D tsx typescript

export GEMINI_API_KEY="발급받은_키"   # https://aistudio.google.com/apikey

npx tsx 예제파일.ts

기본 모델은 gemini-3.6-flash(저비용/고속)를 사용합니다. 더 강한 모델이 필요하면 gemini-2.5-pro로 바꿔 실험해 보세요.

Claude → Gemini 개념 매핑

anthropic.messages.create()ai.models.generateContent()
