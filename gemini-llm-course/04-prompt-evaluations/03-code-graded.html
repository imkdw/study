레슨

의도적으로 단순한 예시로 평가 프로세스에 집중합니다: "이 동물은 다리가 몇 개인가?"를 맞히는 프롬프트를 평가합니다.

2. 초기 프롬프트

function buildInputPrompt(animalStatement: string) {
  return `You will be provided a statement about an animal and your job is to
determine how many legs that animal has.

Here is the animal statement.
<animal_statement>${animalStatement}</animal_statement>

How many legs does the animal have? Please respond with a number`;
}

3. 평가 로직

const outputs = await Promise.all(
  evalData.map((q) => getCompletion(buildInputPrompt(q.animalStatement))),
);

// 결과를 눈으로 검토
for (const [i, output] of outputs.entries()) {
  console.log(`Statement: ${evalData[i].animalStatement}`);
  console.log(`Golden: ${evalData[i].goldenAnswer} | Output: ${output}\n`);
}

// 정확 일치로 채점
function gradeCompletion(output: string, goldenAnswer: string) {
  return output.trim() === goldenAnswer;
}

const grades = outputs.map((o, i) => gradeCompletion(o, evalData[i].goldenAnswer));
const score = grades.filter(Boolean).length / grades.length;
console.log(`Score: ${(score * 100).toFixed(1)}%`);  // 첫 시도: ~67%

발견된 문제

  • 출력 형식 문제: "Based on the statement, the animal has 2 legs." 처럼 숫자만 아닌 응답
  • 답이 틀림: 거미 + 다리 2개 = 8이 아니라 10, 문어 다리 계산 오류

function buildInputPrompt2(animalStatement: string) {

5. 세 번째 시도 — Chain of Thought

function buildInputPrompt3(animalStatement: string) {
  return `You will be provided a statement about an animal and your job is to
determine how many legs that animal has.

Here is the animal statement.
<animal_statement>${animalStatement}</animal_statement>

How many legs does the animal have?
Start by reasoning about the numbers of legs the animal has, thinking step by
step inside of <thinking> tags.
Then, output your final answer inside of <answer> tags.
Inside the <answer> tags return just the number of legs as an integer and
nothing else.`;
}

이제 출력에서 <answer> 태그 안 숫자만 추출해서 채점합니다:

function extractAnswer(text: string): string | null {
  const match = text.match(/<answer>([\s\S]*?)<\/answer>/);
  return match ? match[1].trim() : null;
}

const outputs3 = await Promise.all(
  evalData.map((q) => getCompletion(buildInputPrompt3(q.animalStatement))),
);
const extracted = outputs3.map((o) => extractAnswer(o) ?? "");
const grades3 = extracted.map((o, i) => gradeCompletion(o, evalData[i].goldenAnswer));
console.log(`Score: ${(grades3.filter(Boolean).length / grades3.length * 100).toFixed(1)}%`);
// 원본 결과: 100%
핵심 교훈

평가가 있었기에 "CoT가 정말 도움이 되는가?"를 추측이 아닌 숫자로 확인했습니다. 67% → 75% → 100%. 단, 이 데이터셋은 매우 작으므로 결과를 과신하지 마세요.
