사람 채점 평가 (Human-graded Evals)

GUI 도구로 프롬프트를 프로토타이핑하고 수동 채점으로 비교합니다.

원본: 02_workbench_evals.ipynb

레슨

원본 레슨은 Anthropic Console의 Workbench를 사용합니다. Gemini에서는 Google AI Studio(aistudio.google.com)가 같은 역할을 합니다: 프롬프트를 빠르게 프로토타이핑하고, 파라미터를 바꿔가며 출력을 눈으로 비교할 수 있는 무료 웹 인터페이스입니다.

시나리오: 임의의 언어로 된 코드를 Python으로 번역하는 프롬프트를 만듭니다.

1. 초기 프롬프트 작성

You are a skilled programmer tasked with translating code from one programming
language to Python. Your goal is to produce an accurate and idiomatic Python
translation of the provided source code.

Here is the source code to translate:
<source_code>
{{SOURCE_CODE}}
</source_code>

The source code is written in the following language:
<source_language>
{{SOURCE_LANGUAGE}}
</source_language>

Please translate this code to Python

AI Studio에서는 {{SOURCE_CODE}} 같은 변수를 직접 값으로 치환해서 테스트합니다. 테스트 입력으로 JavaScript, Ruby, C# 코드 조각을 넣어 봅니다.

2. 출력을 보고 채점

초기 프롬프트의 출력에는 보통 이런 문제가 있습니다:

  • "Certainly! Here's the Python translation..." 같은 불필요한 서두 — 출력 토큰 낭비
  • 번역 코드만 뽑기 어려운 형식 — 프로그래밍적으로 파싱 불가
  • 끝에 달리는 장황한 설명 — 이 유스케이스에는 불필요

각 출력에 1-5 점수를 매겨 봅니다. 이 초기 프롬프트는 3/5 정도입니다.

3. 프롬프트 개선

You are a skilled programmer tasked with translating code from one programming
language to Python. Your goal is to produce an accurate and idiomatic Python
translation of the provided source code.

Here is the source code to translate:
<source_code>
{{SOURCE_CODE}}
</source_code>

The source code is written in the following language:
<source_language>
{{SOURCE_LANGUAGE}}
</source_language>

Please translate this code to Python.
Format your response as follows:

<python_code>
Your Python translation here
</python_code>

Only output the <python_code> tags without any other text content

새 출력은 서두도 설명도 없이 <python_code> 태그만 반환합니다. 5/5를 줄 수 있습니다.

4. 버전 비교

프롬프트 v1과 v2의 점수를 나란히 비교하면 "감"이 아니라 수치로 개선을 확인할 수 있습니다. AI Studio는 여러 프롬프트 버전을 저장/비교하는 기능이 제한적이므로, 간단한 스프레드시트나 직접 만든 기록으로 점수를 추적하면 됩니다.

사람 채점의 위치

사람 채점은 프로토타이핑에는 좋지만 확장성이 없습니다. 이 방식으로 감을 잡은 뒤, 다음 레슨부터는 코드 채점과 모델 채점으로 자동화하는 방법을 배웁니다.

TS로 수동 평가 루프 만들기

GUI 대신 같은 과정을 코드로 할 수도 있습니다:

const testCases = [
  { sourceCode: "const chickenCount = 99;", sourceLanguage: "JavaScript" },
  { sourceCode: "class Person; attr_accessor :name; end", sourceLanguage: "Ruby" },
];

for (const [i, tc] of testCases.entries()) {
  const prompt = buildPrompt(tc.sourceCode, tc.sourceLanguage);
  const output = await getCompletion(prompt);
  console.log(`=== Test ${i + 1} ===\n${output}\n`);
  // 출력을 눈으로 보고 점수를 기록
}

연습 2.1 — 나만의 수동 평가

위 코드 번역 프롬프트를 가져와서, 다른 유스케이스(예: 한국어 → 영어 이메일 번역)에 적용해 보세요. 테스트 입력 3개를 정하고, 초기 프롬프트와 개선 프롬프트의 출력에 각각 1-5 점수를 매겨 보세요. 어떤 기준으로 점수를 매겼는지 기록해 두세요 — 그 기준이 나중에 자동 채점 로직의 루브릭이 됩니다.
