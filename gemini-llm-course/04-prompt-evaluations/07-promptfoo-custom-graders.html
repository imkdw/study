promptfoo: 커스텀 코드 grader

내장 assertion으로 부족할 때, 내가 짠 채점 함수를 끼워 넣습니다.

원본: 07_prompt_foo_custom_graders/lesson.ipynb

레슨

이번엔 프롬프트를 YAML에 직접 인라인으로 씁니다. {{topic}}, {{count}} 같은 변수는 Nunjucks 템플릿 문법입니다.

기본 설정

description: Count mentions
prompts:
  - >-
    Write a short paragraph about {{topic}}. Make sure you mention {{topic}}
    exactly {{count}} times, no more or fewer. Only use lower case letters in
    your output.
providers:
  - google:gemini-3.6-flash
  - google:gemini-2.5-pro

YAML 인라인 테스트

tests:
  - vars:
      topic: sheep
      count: 3
  - vars:
      topic: fowl
      count: 2
  - vars:
      topic: gallows
      count: 4
  - vars:
      topic: tweezers
      count: 7
  - vars:
      topic: jeans
      count: 6

promptfoo가 각 테스트의 변수를 템플릿에 치환해 실행합니다. 아직 채점 로직이 없어도 실행해서 변수 치환을 확인할 수 있습니다.

커스텀 grader 함수

"topic이 정확히 count번 등장하는가"는 내장 assertion으로 못 합니다. JS 파일로 직접 grader를 작성합니다. 원본은 Python(get_assert)을 쓰지만 JS도 지원됩니다. count.js:

// count.js — promptfoo는 module.exports로 함수를 찾습니다
module.exports = (output, context) => {
  const topic = context.vars.topic;
  const goalCount = Number(context.vars.count);

  const pattern = new RegExp(`(^|\\\\s)\\\\b${topic}\\\\b`, "g");
  const actualCount = (output.toLowerCase().match(pattern) ?? []).length;

  const pass = goalCount === actualCount;
  return {
    pass,
    score: pass ? 1 : 0,
    reason: `Expected ${topic} to appear ${goalCount} times. Actual: ${actualCount}`,
  };
};

grader 함수는 두 인자를 받습니다:

  • output: 모델의 응답 텍스트
  • context: vars(테스트 변수), prompt 등을 포함하는 객체

반환값은 다음 중 하나:

  • boolean (pass/fail)
  • number (점수)
  • GradingResult 객체: { pass, score, reason }

설정에 연결

defaultTest:
  assert:
    - type: javascript
      value: file://count.js
tests:
  - vars:
      topic: sheep
      count: 3
  # ... 나머지 테스트

defaultTest는 모든 테스트에 이 assertion을 적용하라는 뜻입니다.

npx promptfoo@latest eval
언제 커스텀 grader인가

내장 assertion(contains, regex 등)으로 표현 안 되는 채점 규칙일 때. 예: 단어 출현 횟수, 숫자 범위 검증, JSON 구조 검증 후 값 비교, 출력 길이 제한, 복합 조건 등.

연습 7.1 — 소문자 검증 추가

프롬프트가 "Only use lower case letters"라고 요구합니다. count.js에 "출력이 전부 소문자인지" 검사를 추가해 보세요 (하나라도 대문자가 있으면 실패).

정답 예시 
const hasUpper = /[A-Z]/.test(output);
const pass = goalCount === actualCount && !hasUpper;
return {
  pass,
  score: pass ? 1 : 0,
  reason: hasUpper ? "Output contains uppercase letters" : `count: ${actualCount}/${goalCount}`,
};
