부록 A: 프롬프트 체이닝

"글쓰기는 다시 쓰기다"라는 말처럼, 모델에게 다시 확인하라고 하면 정확도가 올라가는 경우가 많습니다.

예: "'ab'로 끝나는 단어 10개를 말해줘" — 첫 응답에 가짜 단어가 섞일 수 있습니다. 응답을 대화에 넣고 다시 확인하게 합니다:

const firstUser = "Name ten words that all end with the exact letters 'ab'.";

const first = await ai.models.generateContent({
  model: MODEL_NAME,
  contents: [{ role: "user", parts: [{ text: firstUser }] }],
  config: { temperature: 0 },
});
const firstResponse = first.text ?? "";

// 첫 응답을 대화 이력에 넣고 재검토 요청
const contents = [
  { role: "user" as const,  parts: [{ text: firstUser }] },
  { role: "model" as const, parts: [{ text: firstResponse }] },
  { role: "user" as const,  parts: [{ text: "Please find replacements for all 'words' that are not real words." }] },
];
const second = await ai.models.generateContent({ model: MODEL_NAME, contents });
console.log(second.text);

주의점: 이미 정답이어도 모델이 괜히 고치는 경우가 있습니다. 퇴로를 주면 해결됩니다:

"Please find replacements for all 'words' that are not real words. If all the words are real words, return the original list."

체이닝의 일반 패턴: 복잡한 태스크를 여러 호출로 나누고, 앞 호출의 출력을 다음 호출의 입력으로 넣는 것. 각 단계가 단순해져 정확도가 올라갑니다.

부록 B: Tool Use (Function Calling)

도구 사용의 본질은 단순합니다. 모델이 실제로 함수를 실행하는 게 아니라:

  1. 모델이 호출하고 싶은 도구와 인자를 출력한다
  2. 우리 코드가 그 함수를 실제로 실행한다
  3. 결과를 대화에 넣어 다시 모델에게 묻는다

즉, 치환 + 체이닝의 조합입니다. 계산기, 단어 카운터, SQL 쿼리, 날씨 API 등을 줄 수 있습니다.

Gemini에서는 네이티브 Function Calling

원본은 XML 기반 수동 형식(<function_calls>)으로 시뮬레이션하지만, Gemini는 config.tools의 functionDeclarations로 네이티브 지원합니다. 모델이 functionCalls를 반환하고, 우리가 실행한 뒤 functionResponse 파트로 결과를 돌려줍니다. 자세한 구현은 코스 5에서 전체를 다룹니다.

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "Multiply 1,984,135 by 9,343,116",
  config: {
    tools: [{
      functionDeclarations: [{
        name: "calculator",
        description: "Basic arithmetic",
        parameters: {
          type: "object",
          properties: {
            first_operand:  { type: "integer" },
            second_operand: { type: "integer" },
            operator:       { type: "string" },
          },
          required: ["first_operand", "second_operand", "operator"],
        },
      }],
    }],
  },
});
console.log(response.functionCalls);
// [{ name: "calculator", args: { first_operand: 1984135, second_operand: 9343116, operator: "*" } }]

부록 C: 검색과 검색 증강(RAG)

모델이 외부 지식을 검색하게 할 수 있습니다 — 위키피디아, 사내 문서, 벡터 DB 등. 검색 결과를 프롬프트에 넣어 답변의 정확도와 관련성을 높이는 패턴이 RAG입니다.

Gemini에서는 Google Search grounding이 내장되어 있습니다:

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "올해 노벨 문학상 수상자는 누구야?",
  config: {
    tools: [{ googleSearch: {} }],   // 구글 검색 결과를 근거로 답변
  },
});
// groundingMetadata에 실제로 참조한 출처가 담깁니다
console.log(response.candidates?.[0]?.groundingMetadata);

자체 문서 검색을 만들고 싶다면 임베딩 + 벡터 DB 조합이 필요합니다 (Gemini 임베딩: ai.models.embedContent).
