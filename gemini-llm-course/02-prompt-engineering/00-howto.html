튜토리얼 사용법

이 코스의 진행 방식과 공통 실습 환경을 설정합니다.

원본: anthropics/courses — prompt_engineering_interactive_tutorial/00_Tutorial_How-To.ipynb

시작하기

  1. @google/genai 패키지와 tsx를 설치합니다 (코스 1-1 참고).
  2. GEMINI_API_KEY 환경 변수를 설정합니다.
  3. 각 챕터의 코드를 TypeScript 파일로 만들어 npx tsx 파일명.ts로 실행합니다.

공통 헬퍼 함수

이 코스 전체에서 사용하는 공통 셋업입니다. 모든 챕터 파일의 상단에 두세요:

import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({});
const MODEL_NAME = "gemini-3.6-flash";

// 프롬프트를 보내고 텍스트 응답만 받는 헬퍼
async function getCompletion(
  prompt: string,
  systemInstruction = "",
  prefill = "",
) {
  const response = await ai.models.generateContent({
    model: MODEL_NAME,
    contents: [
      { role: "user", parts: [{ text: prompt }] },
      // prefill이 있으면 model 턴으로 넣어 이어쓰게 함
      ...(prefill ? [{ role: "model" as const, parts: [{ text: prefill }] }] : []),
    ],
    config: {
      maxOutputTokens: 2000,
      temperature: 0,   // 이 코스에서는 재현성을 위해 0으로 고정
      ...(systemInstruction ? { systemInstruction } : {}),
    },
  });
  return response.text ?? "";
}

사용 예:

const PROMPT = "안녕, Gemini!";
console.log(await getCompletion(PROMPT));

연습 문제 푸는 법

  • 각 연습에는 바꿔야 할 변수(PROMPT, SYSTEM_PROMPT, PREFILL 등)와 채점 함수(gradeExercise)가 있습니다.
  • 프롬프트를 수정하고 실행해서 채점이 true가 나오면 통과입니다.
  • 막히면 각 연습의 "힌트 보기"를 펼쳐보세요.
왜 temperature 0 인가

이 코스의 모든 실습은 temperature: 0을 사용합니다. 결과가 거의 결정론적이 되어 채점과 비교가 쉬워집니다. 이 코스의 모든 기법은 다른 Gemini 모델에도 그대로 적용됩니다.

Gemini에서의 prefill 주의

원본의 "prefill"(assistant 턴에 말 넣기)은 Gemini에서 role: "model" 메시지로 구현합니다. 대부분 잘 동작하지만 Claude만큼 일관되지 않을 수 있습니다. 프라이밍이 무시되면 지시를 프롬프트에 명시하는 방식으로 보완하세요. 또한 prefill된 텍스트는 응답에 포함되지 않으므로 필요하면 직접 이어붙여야 합니다.
