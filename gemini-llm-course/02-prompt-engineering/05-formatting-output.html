출력 형식 지정과 말 대신해주기

XML 태그 출력, JSON 강제, 그리고 model 턴 프라이밍.

원본: 05_Formatting_Output_and_Speaking_for_Claude.ipynb

셋업

prefill을 지원하는 확장 헬퍼를 씁니다:

async function getCompletion(prompt: string, systemInstruction = "", prefill = "") {
  const response = await ai.models.generateContent({
    model: MODEL_NAME,
    contents: [
      { role: "user", parts: [{ text: prompt }] },
      ...(prefill ? [{ role: "model" as const, parts: [{ text: prefill }] }] : []),
    ],
    config: {
      maxOutputTokens: 2000,
      temperature: 0,
      ...(systemInstruction ? { systemInstruction } : {}),
    },
  });
  return response.text ?? "";
}

레슨

모델은 다양한 형식으로 출력할 수 있습니다. 요청만 하면 됩니다.

XML 태그로 출력 감싸기

2-2에서 "서두 없이"로 해결한 문제를 XML 태그로도 해결할 수 있습니다:

const ANIMAL = "Rabbit";
const PROMPT = `Please write a haiku about ${ANIMAL}. Put it in <haiku> tags.`;

출력이 태그 안에 있으면 프로그램으로 정확히 추출할 수 있습니다:

const response = await getCompletion(PROMPT);
const poem = response.match(/<haiku>([\s\S]*?)<\/haiku>/)?.[1];
console.log(poem);

모델 턴 프라이밍(prefill)

마지막을 model 메시지로 끝내면 모델이 그 지점부터 이어서 씁니다. "speaking for Claude"라 불리는 기법입니다. 여는 태그를 미리 넣어주면 모델이 바로 내용부터 생성합니다:

const ANIMAL = "Cat";
const PROMPT = `Please write a haiku about ${ANIMAL}. Put it in <haiku> tags.`;
const PREFILL = "<haiku>";

const response = await getCompletion(PROMPT, "", PREFILL);
console.log(PREFILL + response);   // 전체를 보려면 prefill을 앞에 붙임

JSON 강제하기

prefill로 {를 넣으면 거의 결정론적으로 JSON 출력이 나옵니다:

const PROMPT = `Please write a haiku about ${ANIMAL}. Use JSON format with the keys as "first_line", "second_line", and "third_line".`;
const PREFILL = "{";

const response = await getCompletion(PROMPT, "", PREFILL);
const json = JSON.parse("{" + response);
Gemini의 더 확실한 방법: responseSchema

Gemini에는 JSON 출력을 강제하는 네이티브 기능이 있습니다:

const response = await ai.models.generateContent({
  model: MODEL_NAME,
  contents: `Write a haiku about ${ANIMAL}.`,
  config: {
    responseMimeType: "application/json",
    responseSchema: {
      type: "object",
      properties: {
        first_line:  { type: "string" },
        second_line: { type: "string" },
        third_line:  { type: "string" },
      },
      required: ["first_line", "second_line", "third_line"],
    },
  },
});
const haiku = JSON.parse(response.text!);  // 스키마가 보장된 JSON

prefill은 여전히 톤/시작 문구를 유도하는 데 유용하지만, 구조화된 출력이 목적이면 responseSchema가 더 강력합니다(코스 5-3에서 다시 다룸).

여러 변수 + 형식 지정 조합

const EMAIL = "Hi Zack, just pinging you for a quick update on that prompt you were supposed to write.";

const response = await getCompletion(PROMPT, "", PREFILL);
보너스 팁

stopSequences에 닫는 XML 태그를 넣으면 모델이 답변 후의 군더더기를 출력하기 전에 멈춥니다 — 비용과 시간 절약:

config: { stopSequences: ["</haiku>"] }

연습 5.1 — 커리가 GOAT?

모델은 강요하면 보통 Michael Jordan을 고릅니다. PREFILL만 바꿔서 Stephen Curry가 최고라고 주장하게 만드세요.

const PROMPT = "Who is the best basketball player of all time? Please choose one specific player.";
const PREFILL = "";   // 여기만 수정

const response = await getCompletion(PROMPT, "", PREFILL);
function gradeExercise(text: string) {
  return /Warrior/.test(text);
}
console.log(response);
console.log("통과:", gradeExercise(response));
힌트 보기

"Warrior"가 나와야 합니다. 모델의 목소리로 더 많은 말을 넣어보세요. "Stephen Curry is the best because," 대신 "Stephen Curry is the best and here are three reasons why. 1:" 처럼요.
