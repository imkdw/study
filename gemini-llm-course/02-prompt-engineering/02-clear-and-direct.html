명확하고 직접적으로

모델은 당신이 말한 것 외에는 아무 맥락도 모릅니다.

원본: 02_Being_Clear_and_Direct.ipynb

셋업

2-0의 공통 getCompletion 헬퍼를 사용합니다 (temperature 0).

레슨

모델은 명확하고 직접적인 지시에 가장 잘 반응합니다.

모델을 첫 출근한 신입으로 생각하세요. 당신이 문자 그대로 말한 것 외에는 아무 맥락도 없습니다. 사람에게 처음 일을 시키듯, 원하는 것을 정확하고 솔직하게 설명할수록 응답이 정확해집니다.

명확한 프롬프팅의 황금률: 프롬프트를 동료에게 보여주고 지시대로 해보라고 하세요. 동료가 헷갈리면 모델도 헷갈립니다.

예시: 하이쿠

"로봇에 대한 하이쿠를 써줘"라고 하면 "하이쿠를 써드리겠습니다:" 같은 서두가 붙습니다. 없애고 싶으면? 그냥 요청하세요:

const PROMPT = "로봇에 대한 하이쿠를 써줘. 서두 없이 바로 시부터 시작해.";
console.log(await getCompletion(PROMPT));

예시: 결론 강요하기

"역대 최고의 농구 선수는 누구야?"라고 물으면 모델은 여러 이름을 나열하며 결론을 피합니다. 하나를 고르게 하려면 명시합니다:

const PROMPT =
  "역대 최고의 농구 선수는 누구야? 의견이 갈리는 건 알지만, " +
  "무조건 한 명만 골라야 한다면 누구를 고르겠어?";
console.log(await getCompletion(PROMPT));

연습

연습 2.1 — 스페인어

SYSTEM_PROMPT를 수정해 모델이 스페인어로 답하게 하세요.

const SYSTEM_PROMPT = "[여기를 수정]";
const PROMPT = "Hello Gemini, how are you?";

const response = await getCompletion(PROMPT, SYSTEM_PROMPT);

function gradeExercise(text: string) {
  return text.toLowerCase().includes("hola");
}
console.log(response);
console.log("통과:", gradeExercise(response));
힌트 보기

"hola"가 포함되면 통과입니다. 사람에게 말하듯 스페인어로 답하라고 시키세요.

연습 2.2 — 선수 한 명만

PROMPT를 수정해 모델이 전혀 망설이지 않고 오직 선수 이름 하나만 — 다른 단어나 구두점 없이 — 답하게 하세요.

const PROMPT = "[여기를 수정]";

const response = await getCompletion(PROMPT);

function gradeExercise(text: string) {
  return text.trim() === "Michael Jordan";
}
console.log(response);
console.log("통과:", gradeExercise(response));
힌트 보기

정확히 "Michael Jordan"만 반환해야 합니다. 사람에게 어떻게 부탁하겠어요? "다른 말 없이 이름만 답해", "이름 외에는 아무것도 쓰지 마" 등 여러 접근이 가능합니다.

연습 2.3 — 긴 이야기

PROMPT를 수정해 800단어 이상의 긴 응답을 얻으세요.

const PROMPT = "[여기를 수정]";

const response = await getCompletion(PROMPT);

function gradeExercise(text: string) {
  return text.trim().split(/\s+/).length >= 800;
}
console.log("통과:", gradeExercise(response));
힌트 보기

LLM은 단어 수를 잘 세지 못하니 목표보다 넉넉하게 요구하세요. 예: "최소 2000단어의 이야기를 써줘".
