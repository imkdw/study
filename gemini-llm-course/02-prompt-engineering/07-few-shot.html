예시 활용 (Few-Shot Prompting)

원하는 행동의 예시를 주는 것이 가장 강력한 기법입니다.

원본: 07_Using_Examples_Few-Shot_Prompting.ipynb

레슨

모델에게 원하는(혹은 원하지 않는) 행동의 예시를 주는 것은 매우 효과적입니다:

  • 올바른 답을 얻기 위해
  • 올바른 형식의 답을 얻기 위해

"few-shot"이라 불리며, shot의 수가 예시 개수입니다. (zero-shot = 예시 없음, one-shot = 1개, n-shot = n개)

예시: 톤 조정

아이들의 질문에 답하는 "부모 봇"을 만든다고 합시다. 그냥 물으면 답이 딱딱하고 기계적입니다:

await getCompletion("Will Santa bring me presents on Christmas?");

원하는 톤을 길게 설명하는 대신, 이상적인 응답 예시를 줄 수 있습니다:

const PROMPT = `Please complete the conversation by writing the next line, speaking as "A".
Q: Is the tooth fairy real?
A: Of course, sweetie. Wrap up your tooth and put it under your pillow tonight. There might be something waiting for you in the morning.
Q: Will Santa bring me presents on Christmas?`;

예시: 형식 학습

복잡한 서식 지시를 단계별로 설명하는 대신, 올바른 형식의 예시를 주면 모델이 패턴을 추론합니다. 아래는 "마을 소개 텍스트에서 인물과 직업을 추출"하는 예시입니다 — 예시 2개를 보여주고 세 번째 마을에 적용하게 합니다:

const PROMPT = `Silvermist Hollow ... (마을 소개 텍스트)
<individuals>
1. Dr. Liam Patel [NEUROSURGEON]
2. Olivia Chen [ARCHITECT]
...
</individuals>

Riverside Grove ... (두 번째 마을 소개)
<individuals>
1. Oliver Hamilton [CHEF]
...
</individuals>

Oak Valley ... (세 번째 마을 소개)`;

const PREFILL = "<individuals>";
const response = await getCompletion(PROMPT, "", PREFILL);
// 모델이 Oak Valley의 인물을 같은 형식으로 추출합니다

예시 사이에 <individuals> 태그로 출력 패턴을 보여주고, prefill로 세 번째 출력의 시작을 지정한 것이 포인트입니다.

예시는 최고의 도구

지식 작업에서 모델의 행동을 원하는 대로 만드는 데 예시만큼 효과적인 도구는 드뭅니다. 엣지 케이스의 예시도 포함하면 좋고, 일반적으로 예시가 많을수록 좋습니다.

연습 7.1 — 예시로 이메일 형식화

연습 6.2를 다시 합니다. 이번엔 few-shot 예시(이메일 + 올바른 분류/형식)를 프롬프트에 넣어 정답을 얻으세요. 모델 출력의 마지막 문자가 카테고리 문자여야 합니다.

const EMAILS = [ /* 연습 6.1과 동일 */ ];
const ANSWERS = [["B"], ["A", "D"], ["C"], ["D"]];

for (const [i, email] of EMAILS.entries()) {
  const prompt = PROMPT.replace("{email}", email);
  const response = await getCompletion(prompt);
  const ok = ANSWERS[i].some((a) => response.trim().endsWith(a));
  console.log(response, "| 통과:", ok);
}
힌트 보기

1) 예시 이메일은 최소 2개. 모든 카테고리를 커버할 필요는 없고, 까다로운 카테고리 위주로. 2) 예시의 답 형식이 정확히 원하는 형식이어야 합니다(답이 카테고리 문자로 끝나도록). 3) 카테고리 목록과 {email} 플레이스홀더는 프롬프트에 유지하세요.
