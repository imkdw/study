환각(Hallucination) 피하기

모델은 때로 사실이 아닌 것을 지어냅니다. 줄이는 기법을 배웁니다.

원본: 08_Avoiding_Hallucinations.ipynb

레슨

나쁜 소식: 모델은 때로 "환각" — 사실이 아니거나 근거 없는 주장을 합니다. 좋은 소식: 최소화하는 기법이 있습니다. 대표적으로:

  • 모르는 질문에 "모른다"고 말할 수 있는 퇴로(out)를 준다
  • 답하기 전에 근거를 먼저 찾게 한다

이 외에도 지금까지 배운 많은 기법이 환각 방지에 도움됩니다. 환각이 보이면 여러 기법을 조합해 실험하세요.

기법 1: 퇴로 주기

도움이 되고 싶어하는 모델은 모르는 것도 지어냅니다:

await getCompletion("Who is the heaviest hippo of all time?");
// 존재하지 않는 "기록상 최대 하마"를 지어낼 수 있음

"모르면 모른다고 해도 된다"는 퇴로를 줍니다:

await getCompletion(
  "Who is the heaviest hippo of all time? Only answer if you know the answer with certainty."
);

기법 2: 근거 먼저 찾기

긴 문서에 질문과 거의 관련 없는 "방해 정보"가 섞여 있으면 모델이 낚여서 틀린 답을 낼 수 있습니다. 예: Matterport의 SEC 문서에서 "2020년 5월 31일의 구독자 수"를 물으면 문서에 없는 숫자를 지어냅니다.

답 전에 관련 인용을 먼저 추출하고, 근거가 충분한지 판단하게 합니다:

const PROMPT = `<question>What was Matterport's subscriber base on the precise date of May 31, 2020?</question>
Please read the below document. Then, first identify the most relevant quotes in <quotes> tags, decide whether the quotes answer the question, and only then write your answer in <answer> tags. If the document doesn't contain the answer, say so.

<document>
Matterport SEC filing 10-K 2023 ... (긴 문서)
</document>`;
문서-질문 순서

다음 챕터에서 배우겠지만 질문은 문서 뒤에 두는 게 모범 사례입니다. 여기선 가독성을 위해 위에 뒀습니다.

보너스: temperature 낮추기

환각은 temperature를 낮춰 완화할 수도 있습니다. 0에 가까울수록 답변이 일관되고, 1에 가까울수록 창의적이지만 변동성이 큽니다. 사실 기반 작업은 낮은 temperature가 안전합니다.

연습

연습 8.1 — 비욘세 환각

Beyoncé의 여덟 번째 스튜디오 앨범은 존재하지 않습니다 (Renaissance가 일곱 번째). 그런데 모델은 "2022년 Renaissance"처럼 지어낸 답을 할 수 있습니다. PROMPT를 수정해 모델에게 퇴로를 주어 환각을 막으세요.

const PROMPT = "In what year did star performer Beyoncé release her eighth studio album?";

const response = await getCompletion(PROMPT);

function gradeExercise(text: string) {
  const admits = /Unfortunately|I do not|I don't/.test(text);
  const noHallucination = !/2022/.test(text);
  return admits && noHallucination;
}
console.log(response);
console.log("통과:", gradeExercise(response));
힌트 보기

"I do not", "I don't", "Unfortunately" 같은 표현이 나오고 "2022"가 없으면 통과. 모델이 답을 모를 때 무엇을 해야 할까요?

연습 8.2 — 문서 기반 답변

Matterport SEC 문서(긴 발췌문)를 프롬프트에 넣고 "2018년 12월부터 2022년 12월까지 구독자가 얼마나 늘었나?"를 묻습니다. 정답은 49배(49-fold)입니다. 환각을 막기 위해 인용(citation)을 먼저 요구하도록 프롬프트를 고치세요.

힌트 보기

응답에 "49-fold"가 있으면 통과. 관련 인용을 먼저 뽑고, 그 인용이 충분한 근거인지 판단하게 한 뒤 답하게 하세요.
