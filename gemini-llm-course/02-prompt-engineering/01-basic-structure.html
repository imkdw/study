기본 프롬프트 구조

generateContent의 필수 요소와 systemInstruction의 역할을 배웁니다.

원본: 01_Basic_Prompt_Structure.ipynb

셋업

import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({});
const MODEL_NAME = "gemini-3.6-flash";

async function getCompletion(prompt: string, systemInstruction = "") {
  const response = await ai.models.generateContent({
    model: MODEL_NAME,
    contents: [{ role: "user", parts: [{ text: prompt }] }],
    config: {
      maxOutputTokens: 2000,
      temperature: 0,
      ...(systemInstruction ? { systemInstruction } : {}),
    },
  });
  return response.text ?? "";
}

레슨

generateContent 호출의 최소 필수 요소:

  • model: 사용할 모델 ID
  • contents: 입력 메시지 배열(또는 문자열). 각 메시지는 role과 parts를 가지며, user/model이 번갈아 나오고 반드시 user로 시작합니다

선택 옵션(config 안):

  • systemInstruction: 시스템 프롬프트 (아래 참고)
  • temperature: 응답의 변동성. 이 코스에서는 0으로 고정합니다
  • maxOutputTokens: 생성할 최대 토큰 수(하드 스톱 — 단어 중간에서도 끊김)

올바른 형식의 예

console.log(await getCompletion("안녕 Gemini, 잘 지내?"));
console.log(await getCompletion("바다의 색깔을 알려줘"));
console.log(await getCompletion("셀린 디온은 몇 년생이야?"));

잘못된 형식의 예

// 에러: role/parts 없이 문자열 배열만 넣음
contents: ["안녕?"]   // 이러면 SDK가 user로 감싸주긴 하지만 구조화된 대화는 불가

// 에러: user가 연속 두 번 — user/model은 번갈아야 함
contents: [
  { role: "user", parts: [{ text: "셀린 디온은 몇 년생이야?" }] },
  { role: "user", parts: [{ text: "그녀에 대한 다른 사실도 알려줘" }] },
]

user와 model 메시지는 반드시 번갈아 나오고, 반드시 user로 시작해야 합니다. 여러 user/model 쌍을 넣어 멀티턴 대화를 흉내낼 수 있고, 마지막을 model로 끝내면 모델이 거기서 이어서 생성합니다(뒤 챕터에서 다룸).

시스템 프롬프트

시스템 프롬프트는 질문/태스크를 주기 전에 모델에게 맥락, 지시, 가이드라인을 제공하는 방법입니다. 구조적으로는 대화 메시지와 분리되어 config.systemInstruction에 넣습니다.

const SYSTEM_PROMPT =
  "항상 답 대신 대화를 발전시키는 비판적 사고 질문들로만 답해줘. 절대 질문에 답하지 마.";

console.log(await getCompletion("하늘은 왜 파란색이야?", SYSTEM_PROMPT));

잘 작성된 시스템 프롬프트는 규칙 준수 능력을 포함해 모델의 성능을 높입니다.

연습

연습 1.1 — 3까지 세기

PROMPT를 수정해 모델이 1, 2, 3까지 세게 만드세요.

const PROMPT = "[여기를 수정]";

const response = await getCompletion(PROMPT);

function gradeExercise(text: string) {
  return /1/.test(text) && /2/.test(text) && /3/.test(text);
}

console.log(response);
console.log("통과:", gradeExercise(response));
힌트 보기

채점 함수는 "1", "2", "3" 숫자가 모두 포함된 답을 찾습니다. 그냥 시키면 됩니다 — 모델은 대부분 요청만으로도 잘 따릅니다.

연습 1.2 — 시스템 프롬프트

SYSTEM_PROMPT를 수정해 모델이 3살짜리 아이처럼 대답하게 만드세요.

const SYSTEM_PROMPT = "[여기를 수정]";
const PROMPT = "하늘은 얼마나 커?";

const response = await getCompletion(PROMPT, SYSTEM_PROMPT);

function gradeExercise(text: string) {
  return /giggles|soo/i.test(text);   // 원본 기준. 한국어 실습이면 기준을 바꿔보세요
}

console.log(response);
console.log("통과:", gradeExercise(response));
힌트 보기

채점 함수는 "soo"나 "giggles"를 찾습니다. 사람에게 말하듯 역할을 지시하면 됩니다. 예: "너는 3살짜리 아이야."
