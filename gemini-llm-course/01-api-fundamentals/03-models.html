Gemini 모델 계열

Gemini 모델은 크게 세 축으로 나뉩니다. 모델을 고를 때 고려할 요소는:

  • 지연시간(latency): 얼마나 빠른가
  • 능력(capability): 얼마나 똑똑한가
  • 비용: 얼마나 비싼가
모델 ID (예시)특징적합한 용도
gemini-3.6-flash-lite가장 빠르고 저렴분류, 단순 변환, 대량 처리
gemini-3.6-flash속도-성능 균형일반 챗봇, 요약, 대부분의 학습 실습
gemini-2.5-pro가장 강력복잡한 추론, 코딩, 긴 문맥 분석
최신 모델 목록 확인

모델 ID는 계속 추가/변경됩니다. 사용 가능한 모델은 코드로 확인할 수 있습니다:

const pager = await ai.models.list();
for await (const m of pager) {
  console.log(m.name);
}

또는 Gemini 모델 문서를 참고하세요.

모델 속도 비교하기

같은 프롬프트를 여러 모델에 보내고 응답 시간을 측정하는 함수입니다:

import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({});

async function compareModelSpeeds() {
  const models = ["gemini-2.5-pro", "gemini-3.6-flash", "gemini-3.6-flash-lite"];
  const task = "광합성의 개념을 한 문단으로 간결하게 설명해줘.";

  for (const model of models) {
    const start = performance.now();

    const response = await ai.models.generateContent({
      model,
      contents: task,
      config: { maxOutputTokens: 500 },
    });

    const elapsed = (performance.now() - start) / 1000;
    const tokens = response.usageMetadata?.candidatesTokenCount ?? 0;
    const perToken = tokens > 0 ? elapsed / tokens : 0;

    console.log(`모델: ${model}`);
    console.log(`응답: ${response.text}`);
    console.log(`생성 토큰: ${tokens}`);
    console.log(`실행 시간: ${elapsed.toFixed(2)}초`);
    console.log(`토큰당 시간: ${perToken.toFixed(3)}초\n`);
  }
}

await compareModelSpeeds();

"간결하게 설명해줘" 같은 단순 프롬프트에서는 모든 모델이 잘 해냅니다. 이런 경우 가장 빠르고 저렴한 모델을 고르는 게 합리적입니다.

모델 성능 비교하기

빠른 모델이 있는데 왜 비싼 모델을 쓸까요? 난이도가 올라가면 차이가 납니다. 아래 함수는 약간 까다로운 수학 문제(기하평균 계산)를 각 모델에 7번씩 던져 정답률을 봅니다. 정답은 18입니다:

async function compareModelCapabilities() {
  const models = ["gemini-2.5-pro", "gemini-3.6-flash", "gemini-3.6-flash-lite"];
  const task = `What is the geometric monthly fecal coliform mean of a distribution
system with the following FC counts: 24, 15, 7, 16, 31 and 23? The result will be
inputted into a NPDES DMR, therefore, round to the nearest whole number.
Respond only with a number and nothing else.`;

  for (const model of models) {
    const answers: string[] = [];
    for (let i = 0; i < 7; i++) {
      const response = await ai.models.generateContent({
        model,
        contents: task,
        config: { maxOutputTokens: 1000 },
      });
      answers.push(response.text ?? "");
    }
    console.log(`모델: ${model}`);
    console.log(`답변:`, answers);
  }
}

await compareModelCapabilities();
주의

이 데모는 교육용입니다. 진지한 모델 비교는 업계 표준 벤치마크나 여러분의 실제 태스크에 대한 평가(eval)로 해야 합니다. 코스 4에서 다룹니다.

어떤 모델을 고를까

  • 능력: 태스크가 요구하는 추론/지식 수준을 모델이 감당하는가
  • 속도: 실시간 인터랙션이 필요한가 (챗봇, 자동완성)
  • 비용: 호출량 × 토큰 단가가 예산 안인가

한 가지 접근법: Flash로 시작하기

실험 단계에서는 gemini-3.6-flash(또는 더 저렴한 flash-lite)로 시작을 권합니다. 빠르고 저렴해서 프롬프트를 빠르게 반복 개선할 수 있고, 많은 태스크에서 충분히 좋은 결과를 냅니다. 결과가 아쉬우면 Pro로 "업그레이드"하면 됩니다.

평가와 업그레이드

모델 선택을 감으로 하지 마세요. 내 유스케이스에 맞는 평가 세트를 만들어 두면 "업그레이드가 필요한가?"를 수치로 판단할 수 있습니다. 이것이 코스 4의 주제입니다.
