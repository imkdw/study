생성 파라미터

maxOutputTokens, temperature, stopSequences의 역할을 이해합니다.

원본: anthropics/courses — anthropic_api_fundamentals/04_parameters.ipynb

학습 목표

  • maxOutputTokens의 역할을 이해한다
  • temperature로 응답의 무작위성을 제어한다
  • stopSequences의 용도를 설명할 수 있다

maxOutputTokens

Gemini 요청의 필수 요소는 model과 contents뿐이지만, 출력 길이를 제한하려면 config.maxOutputTokens를 사용합니다.

토큰이란

LLM은 단어가 아니라 토큰이라는 텍스트 조각 단위로 작동합니다. 프롬프트가 토큰으로 변환되어 들어가고, 모델은 출력을 한 토큰씩 생성합니다. 영어 기준 1토큰은 대략 3~4자에 해당합니다.

Gemini만의 기능: countTokens

Gemini API는 요청 전에 입력이 몇 토큰인지 미리 계산할 수 있습니다:

const result = await ai.models.countTokens({
  model: "gemini-3.6-flash",
  contents: "아주 긴 프롬프트 텍스트...",
});
console.log(result.totalTokens);

maxOutputTokens 실험

10 토큰으로 제한하면 출력이 잘립니다:

const truncated = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "시 한 편 써줘",
  config: { maxOutputTokens: 10 },
});
console.log(truncated.text);
// 시 한 편을 써드리겠습니다:
//
// (중간에 끊김)

모델이 왜 멈췄는지는 finishReason으로 확인합니다:

console.log(truncated.candidates?.[0]?.finishReason);
// "MAX_TOKENS"  -> 토큰 한도에 걸려서 멈춤
// "STOP"        -> 모델이 자연스럽게 완성하고 멈춤
중요한 오해 바로잡기
  • 모델은 maxOutputTokens를 "모르고" 생성합니다. 값을 바꿔도 생성 방식은 동일하고, 여유를 주거나 잘라낼 뿐입니다.
  • 값을 크게 해도 그만큼 길게 쓰는 게 아닙니다. 1000으로 줘도 농담 하나는 55 토큰에서 끝납니다.

왜 조절하는가

  • 비용/한도: 입출력 토큰 모두 과금 대상입니다.
  • 성능: 생성 토큰이 늘수록 응답 시간이 선형으로 길어집니다.
  • 품질: 너무 작으면 답변이 잘려 불완전해집니다.
// 출력 길이에 따른 소요 시간 비교
async function compareNumTokensSpeed() {
  const task = `소셜 미디어가 정신 건강에 미치는 영향에 대해
두 인물이 서로 다른 의견으로 토론하는 아주 긴 대화를 만들어줘.`;

  for (const maxOutputTokens of [100, 1000, 4096]) {
    const start = performance.now();
    const response = await ai.models.generateContent({
      model: "gemini-3.6-flash",
      contents: task,
      config: { maxOutputTokens },
    });
    const elapsed = (performance.now() - start) / 1000;
    console.log(`생성 토큰: ${response.usageMetadata?.candidatesTokenCount}`);
    console.log(`소요 시간: ${elapsed.toFixed(2)}초\n`);
  }
}

stopSequences

모델이 특정 문자열을 생성하는 순간 멈추게 하는 장치입니다. "이걸 생성하면 거기서 멈춰!"라고 말하는 것과 같습니다.

JSON 객체를 만들어 달라고 하면 모델은 설명까지 덧붙이는 경우가 많습니다:

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "이름, 이메일, 전화번호를 가진 사람을 나타내는 JSON 객체를 만들어줘.",
});
// JSON 뒤에 "이 객체에는 3개의 키-값 쌍이 있습니다..." 같은 설명이 따라올 수 있음

}를 stop sequence로 주면 닫는 괄호 직후에 생성이 멈춥니다:

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "이름, 이메일, 전화번호를 가진 사람을 나타내는 JSON 객체를 만들어줘.",
  config: { stopSequences: ["}"] },
});
console.log(response.text);
주의: stop sequence 자체는 출력에 포함되지 않음

출력이 } 직전에서 끝나므로, JSON으로 파싱하려면 끝에 "}"를 직접 붙여줘야 합니다. 또한 Claude와 달리 Gemini는 어떤 stop sequence에 걸렸는지 응답에 담지 않고 finishReason이 STOP으로 나옵니다.

여러 개를 줄 수도 있고, 그중 아무거나 먼저 나오면 멈춥니다:

config: { stopSequences: ["b", "c"] }   // "b"나 "c"를 생성하는 순간 멈춤

temperature

temperature는 응답의 "무작위성"과 "창의성"을 조절합니다. 0에 가까울수록 결정론적이고 안전한 선택을, 높을수록 다양하고 예측 불가한 출력을 냅니다. Gemini의 기본값은 모델마다 다르지만 보통 1.0 근처입니다.

동작 원리: 모델은 다음 토큰의 확률 분포를 예측합니다. 낮은 temperature는 분포를 뾰족하게 만들어 최확률 토큰만 고르게 하고, 높은 temperature는 분포를 평평하게 만들어 덜 가능한 토큰도 선택되게 합니다.

분석/사실 작업에는 0에 가깝게, 창작 작업에는 1에 가깝게 설정하세요.
async function demonstrateTemperature() {
  for (const temperature of [0, 1]) {
    console.log(`temperature = ${temperature} 로 3회 요청`);
    console.log("================");
    for (let i = 0; i < 3; i++) {
      const response = await ai.models.generateContent({
        model: "gemini-3.6-flash",
        contents: "외계 행성 이름을 지어줘. 단어 하나로만 답해.",
        config: { maxOutputTokens: 100, temperature },
      });
      console.log(`응답 ${i + 1}: ${response.text}`);
    }
  }
}

temperature=0이면 3번 모두 같은 이름(예: "Xendor")이 나오고, temperature=1이면 매번 다른 이름이 나옵니다. 단, 0이라도 완전히 결정론적인 것은 아니며, 그저 매우 유사해질 뿐입니다.

systemInstruction (시스템 프롬프트)

대화 전체에 적용되는 상위 지시입니다. 모델의 역할, 톤, 맥락을 정의합니다:

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "안녕! 잘 지내?",
  config: {
    systemInstruction: "너는 항상 프랑스어로만 답하는 외국어 튜터야.",
    maxOutputTokens: 1000,
  },
});
// Bonjour ! Ravi de vous rencontrer. Comment allez-vous ?
  • 선택 사항이지만 톤과 맥락 설정에 유용합니다.
  • 대화 전체에 적용되므로 매 user 메시지에 지시를 반복할 필요가 없습니다.
  • 톤/맥락/역할은 systemInstruction에, 구체적 지시와 데이터는 user 턴에 두는 게 좋습니다.
실습: generateQuestions 함수

topic과 numQuestions를 받아, 주제에 대한 사고를 자극하는 질문을 번호 목록으로 생성하는 함수를 작성하세요. 다음 파라미터를 모두 사용해야 합니다:

  • maxOutputTokens: 응답을 1000 토큰 이하로 제한
  • systemInstruction: 해당 주제의 전문가이며 번호 목록을 생성하라고 지시
  • stopSequences: 정확한 개수만큼만 생성되도록 (3개를 요청하면 "4."가 나오는 순간 멈추기)
정답 보기 
async function generateQuestions(topic: string, numQuestions = 3) {
  const response = await ai.models.generateContent({
    model: "gemini-3.6-flash",
    contents: `${topic}에 대한 질문 ${numQuestions}개를 번호 목록으로 생성해줘.`,
    config: {
      maxOutputTokens: 500,
      systemInstruction:
        `너는 ${topic}의 전문가야. 주제에 대한 사고를 자극하는 질문을 생성해.`,
      stopSequences: [`${numQuestions + 1}.`],
    },
  });
  console.log(response.text);
}

await generateQuestions("자유의지", 3);
