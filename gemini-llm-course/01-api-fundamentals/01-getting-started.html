Gemini SDK 시작하기

필요한 패키지를 설치하고, 인증을 설정하고, 첫 번째 요청을 내봅니다.

원본: anthropics/courses — anthropic_api_fundamentals/01_getting_started.ipynb

학습 목표

  • @google/genai 패키지를 설치하고 API 키로 인증한다
  • Gemini 모델에 첫 번째 요청을 보내고 응답을 출력한다

SDK 설치

Gemini API용 공식 TypeScript/JavaScript SDK는 @google/genai입니다. (구형 @google/generative-ai 패키지는 deprecated이므로 반드시 이 패키지를 사용합니다.)

Node.js 20 이상이 필요하고, SDK 3.0.0부터는 Node.js 22 이상이 요구됩니다.

node --version   # v20 이상 권장 (v22+면 안전)

npm install @google/genai
npm install -D tsx typescript   # TS 파일을 바로 실행하기 위한 개발 의존성

API 키 발급

  1. Google AI Studio에 Google 계정으로 로그인합니다.
  2. "Get API key" 메뉴에서 API 키를 생성합니다. 무료 티어가 제공되어 학습용으로 충분합니다.
  3. 키는 생성 직후 한 번만 전체가 보이니 바로 복사해 둡니다.
API 키는 비밀번호처럼 취급

코드에 하드코딩하거나 git에 커밋하지 마세요. 환경 변수나 .env 파일로 관리하고, .gitignore에 .env를 꼭 추가합니다.

API 키 안전하게 저장하기

가장 간단한 방법은 환경 변수입니다:

export GEMINI_API_KEY="여기에_키_붙여넣기"

프로젝트 단위로 관리하려면 .env 파일과 dotenv 패키지를 사용합니다:

npm install dotenv
# .env
GEMINI_API_KEY=여기에_키_붙여넣기
import "dotenv/config";   // 파일 최상단에서 .env를 로드

클라이언트 생성과 첫 요청

GoogleGenAI 객체가 API의 진입점입니다. process.env.GEMINI_API_KEY가 설정되어 있으면 인자 없이 생성해도 자동으로 키를 읽습니다.

import { GoogleGenAI } from "@google/genai";

const ai = new GoogleGenAI({});  // GEMINI_API_KEY 환경 변수를 자동으로 읽음

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "안녕! 애완 닭에 대한 하이쿠를 써줘",
});

console.log(response.text);

실행하면 이런 응답이 나옵니다:

깃털 친구가 우는 소리
하루 종일 흙을 파헤치네
충실한 애완 닭
원본과의 차이

원본은 client.messages.create({ model, max_tokens, messages })를 사용합니다. Gemini는 ai.models.generateContent({ model, contents, config })를 쓰고, max_tokens 같은 옵션은 config 객체 안에 넣습니다. 또한 Gemini의 maxOutputTokens는 필수가 아니므로 생략할 수 있습니다.

응답 객체 살펴보기

response.text는 편의 접근자입니다. 전체 응답을 출력보면 더 많은 정보가 있습니다:

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "하이를 프랑스어로 번역해줘. 단어 하나로만 답해",
});

console.log(response.text);
// Bonjour.

console.log(response.usageMetadata);
// { promptTokenCount: 12, candidatesTokenCount: 3, totalTokenCount: 15, ... }
