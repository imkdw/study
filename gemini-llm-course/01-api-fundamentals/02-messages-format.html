import { GoogleGenAI } from "@google/genai";

contents 포맷

Gemini에서 대화 이력은 contents 배열로 전달합니다. 각 요소는 role과 parts를 가진 객체입니다:

  • role: "user"(사용자) 또는 "model"(모델의 이전 응답)
  • parts: { text: "..." } 같은 파트 객체의 배열 (텍스트, 이미지, 함수 호출 등)
const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: [
    { role: "user", parts: [{ text: "Dr. Pepper에는 어떤 향료가 들어가?" }] },
  ],
});

메시지 하나뿐이라면 문자열을 바로 넘겨도 됩니다(내부적으로 user 파트로 변환됩니다):

contents: "Dr. Pepper에는 어떤 향료가 들어가?"

여러 턴의 대화 이력은 이렇게 생겼습니다:

const contents = [
  { role: "user",  parts: [{ text: "안녕! 잘 지내?" }] },
  { role: "model", parts: [{ text: "안녕하세요! 잘 지냅니다. 무엇을 도와드릴까요?" }] },
  { role: "user",  parts: [{ text: "흰족제비에 대한 재밌는 사실 하나 알려줘" }] },
  { role: "model", parts: [{ text: "흥분한 족제비는 '두킹(dooking)'이라는 소리를 냅니다!" }] },
];
규칙
  • 메시지는 반드시 user로 시작해야 합니다.
  • user와 model이 번갈아 나와야 합니다.
  • 역할 이름이 Claude의 "assistant"와 달리 Gemini는 "model"입니다.

이 포맷 덕분에 맥락 보존이 됩니다. 전체 대화를 매번 내므로 모델이 이전 내용을 기억한 것처럼 응답합니다. 물론 메시지 하나만 보내는 것도 완전히 정상입니다.

퀴즈

각 메시지에 필요한 두 필드는?

  • a) "sender"와 "text"
  • b) "role"과 "parts"
  • c) "user"와 "model"
  • d) "input"과 "output"
정답 보기

b — 모든 메시지는 role과 parts를 가집니다. (문자열 단축형을 쓰면 SDK가 { role: "user", parts: [{ text }] }로 바꿔줍니다.)

응답 객체 뜯어보기

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "hello를 프랑스어로 번역해. 단어 하나로만 답해",
});

console.log(response.text);   // Bonjour.

GenerateContentResponse의 주요 필드:

필드설명
response.text생성된 텍스트를 모아둔 편의 접근자. 가장 많이 씁니다
response.candidates응답 후보 배열. candidates[0].content.parts에 실제 파트가 들어있습니다
candidates[0].finishReason생성이 멈춘 이유 (STOP, MAX_TOKENS, SAFETY 등)
response.usageMetadatapromptTokenCount(입력), candidatesTokenCount(출력), totalTokenCount
response.functionCalls모델이 요청한 함수 호출 목록 (코스 5에서 다룸)
실습: translate 함수

두 인자 word(단어)와 language(언어)를 받는 translate 함수를 작성하세요. Gemini에게 번역을 요청해 결과를 반환해야 합니다.

await translate("hello", "Spanish");
// 'The word "hello" translated into Spanish is: Hola'

보너스: 번역된 단어만 반환하도록 프롬프트를 다듬어 보세요.

정답 보기 
async function translate(word: string, language: string) {
  const response = await ai.models.generateContent({
    model: "gemini-3.6-flash",
    contents: `Translate the word ${word} into ${language}. ` +
              `Only respond with the translated word, nothing else`,
  });
  return response.text;
}

메시지 리스트 활용 패턴

모델 입에 말 넣기(출력 프라이밍)

마지막 메시지를 model로 끝내면, Gemini는 그 텍스트를 이어서 생성합니다. 예를 들어 하이쿠의 첫 줄을 "고요한 산바람"으로 시작하게 하려면:

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: [
    { role: "user",  parts: [{ text: "아름다운 하이쿠를 지어줘" }] },
    { role: "model", parts: [{ text: "고요한 산바람," }] },
  ],
});
console.log(response.text);

출력은 모델이 이어서 쓴 나머지 부분입니다. 전체 하이쿠를 얻으려면 앞부분을 직접 붙입니다:

console.log("고요한 산바람," + response.text);
Gemini에서의 주의점

이 기법은 잘 동작하지만 모델 버전에 따라 프라이밍 문구를 반복 출력하거나 무시하는 경우가 있습니다. 결과가 이상하면 config.systemInstruction이나 명시적 지시로 보완하세요.

Few-shot 프롬프팅

대화 이력에 입출력 예시를 넣어 응답 형식을 유도할 수 있습니다. 트윗 감정 분석을 "POSITIVE" 또는 "NEGATIVE" 한 단어로 받고 싶다면:

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: [
    { role: "user",  parts: [{ text: "비주류 의견: 피클은 역겨워" }] },
    { role: "model", parts: [{ text: "NEGATIVE" }] },
    { role: "user",  parts: [{ text: "피클 사랑이 도를 넘은 것 같아. 피클 모양 튜브를 샀어" }] },
    { role: "model", parts: [{ text: "POSITIVE" }] },
    { role: "user",  parts: [{ text: "도대체 왜 피클을 먹어? 진짜 맛없어!" }] },
    { role: "model", parts: [{ text: "NEGATIVE" }] },
    { role: "user",  parts: [{ text: "@PickleCo 매운 피클 먹어봤는데 미각이 춤을 춰!" }] },
  ],
});
console.log(response.text);   // POSITIVE

예시 없이 물어보면 길고 장황한 분석이 나오는데, 예시 3개로 한 단어 답변을 얻었습니다. 이것이 few-shot 프롬프팅의 핵심입니다(코스 2-7에서 깊게 다룹니다).

실습: 멀티턴 챗봇 만들기

대화형 챗봇을 만드세요. 순서는:

  1. 대화 이력을 저장할 배열을 만든다
  2. 사용자 입력을 받아 이력에 추가한다
  3. 이력 전체를 Gemini에 보낸다
  4. 응답을 출력하고 model 메시지로 이력에 추가한다
  5. 반복한다 ("quit" 입력 시 종료)

힌트: Node에서는 readline 모듈로 입력을 받을 수 있습니다. 또는 ai.chats.create()를 쓰면 이력 관리를 SDK가 대신합니다.

정답 보기 (수동 이력 관리) 
import { GoogleGenAI } from "@google/genai";
import readline from "node:readline";

const ai = new GoogleGenAI({});
const rl = readline.createInterface({ input: process.stdin, output: process.stdout });
const question = (q: string) => new Promise<string>((res) => rl.question(q, res));

const history: { role: "user" | "model"; parts: { text: string }[] }[] = [];

while (true) {
  const input = await question("You: ");
  if (input.toLowerCase() === "quit") break;

  history.push({ role: "user", parts: [{ text: input }] });

  const response = await ai.models.generateContent({
    model: "gemini-3.6-flash",
    contents: history,
  });

  const reply = response.text ?? "";
  console.log(`Gemini: ${reply}`);
  history.push({ role: "model", parts: [{ text: reply }] });
}
rl.close();
정답 보기 (Chats API 사용 — 더 간단) 
import { GoogleGenAI } from "@google/genai";
import readline from "node:readline";

const ai = new GoogleGenAI({});
const rl = readline.createInterface({ input: process.stdin, output: process.stdout });
const question = (q: string) => new Promise<string>((res) => rl.question(q, res));

const chat = ai.chats.create({ model: "gemini-3.6-flash" });  // 이력 자동 관리

while (true) {
  const input = await question("You: ");
  if (input.toLowerCase() === "quit") break;

  const response = await chat.sendMessage({ message: input });
  console.log(`Gemini: ${response.text}`);
}
rl.close();
