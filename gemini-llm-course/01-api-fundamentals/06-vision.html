이미지 프롬프팅(비전)

텍스트와 이미지를 함께 보내는 멀티모달 프롬프트를 만듭니다.

원본: anthropics/courses — anthropic_api_fundamentals/06_vision.ipynb

비전 기능

Gemini 모델은 기본적으로 멀티모달입니다. Flash, Pro 모두 이미지를 이해할 수 있습니다. 이미지를 넣으려면 메시지의 parts 배열에 이미지 파트를 넣습니다.

파트(parts) 기반 메시지

지금까지 parts: [{ text: "..." }]만 썼지만, 파트에는 여러 종류가 있습니다:

  • { text: "..." } — 텍스트
  • { inlineData: { mimeType, data } } — base64로 인코딩된 바이너리(이미지 등)
  • { fileData: { fileUri, mimeType } } — Files API에 업로드된 파일 참조

하나의 메시지에 파트를 여러 개 섞어 넣을 수 있고, 이것이 멀티모달 프롬프트의 기본입니다.

이미지 단독 프롬프트

로컬 이미지를 보내는 절차:

  1. 파일을 바이너리로 읽는다
  2. base64 문자열로 인코딩한다
  3. inlineData 파트로 감싼다
import { readFileSync } from "node:fs";

const base64 = readFileSync("./sunburn.png").toString("base64");

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: [
    {
      role: "user",
      parts: [
        { inlineData: { mimeType: "image/png", data: base64 } },
      ],
    },
  ],
});
console.log(response.text);
// 지시가 없으면 모델이 이미지를 설명합니다

지원 MIME 타입: image/png, image/jpeg, image/webp, image/gif, image/heic 등.

이미지 + 텍스트 프롬프트

텍스트 파트를 함께 넣으면 됩니다:

contents: [
  {
    role: "user",
    parts: [
      { inlineData: { mimeType: "image/png", data: base64 } },
      { text: "이 사람이 이 상황을 예방하려면 어떻게 했어야 할까?" },
    ],
  },
]

여러 이미지

이미지 파트를 여러 개 넣으면 됩니다:

parts: [
  { text: "이미지 1:" },
  { inlineData: { mimeType: "image/png", data: img1 } },
  { text: "이미지 2:" },
  { inlineData: { mimeType: "image/png", data: img2 } },
  { text: "이미지 3:" },
  { inlineData: { mimeType: "image/png", data: img3 } },
  { text: "이 이미지들의 공통점은 뭐야?" },
]
팁: 이미지에 라벨 붙이기

여러 이미지를 보낼 때 "이미지 1:", "이미지 2:" 같은 텍스트 라벨을 앞에 붙이면 모델이 각 이미지를 구분해 참조하기 쉬워집니다. 저사양 모델일수록 효과가 큽니다.

이미지 파트 헬퍼 함수

import { readFileSync } from "node:fs";
import { extname } from "node:path";

const MIME: Record<string, string> = {
  ".png": "image/png", ".jpg": "image/jpeg", ".jpeg": "image/jpeg",
  ".webp": "image/webp", ".gif": "image/gif",
};

function imagePart(path: string) {
  const mimeType = MIME[extname(path).toLowerCase()];
  if (!mimeType) throw new Error(`지원하지 않는 형식: ${path}`);
  return {
    inlineData: { mimeType, data: readFileSync(path).toString("base64") },
  };
}

URL 이미지

로컬에 없는 이미지는 fetch로 받아서 같은 방식으로 인코딩합니다:

async function imagePartFromUrl(url: string) {
  const res = await fetch(url);
  const mimeType = res.headers.get("content-type") ?? "image/jpeg";
  const data = Buffer.from(await res.arrayBuffer()).toString("base64");
  return { inlineData: { mimeType, data } };
}

const parts = [
  { text: "이미지 1:" },
  await imagePartFromUrl(url1),
  { text: "이미지 2:" },
  await imagePartFromUrl(url2),
  { text: "두 이미지의 공통점은?" },
];

Files API (큰 파일/재사용)

큰 이미지나 반복 사용하는 파일은 Files API로 업로드 후 URI로 참조합니다:

const file = await ai.files.upload({
  file: "./big-photo.jpg",
  config: { mimeType: "image/jpeg" },
});

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: [{
    role: "user",
    parts: [
      { fileData: { fileUri: file.uri!, mimeType: file.mimeType! } },
      { text: "이 사진을 설명해줘" },
    ],
  }],
});

인라인 데이터는 요청당 약 20MB 제한이 있으므로, 그 이상이면 Files API를 씁니다.

비전 프롬프팅 팁

구체적으로 물어보기

텍스트 프롬프트와 마찬가지로 구체적 지시가 성능을 올립니다. 예: "이 사진에 몇 명이 있어?"보다 아래가 낫습니다:

{ text: `너는 이미지 속 객체를 세는 데 완벽한 시각과 세심함을 가진 전문가야.
이 사진에 몇 명이 있는지 세어줘. 일부 사람은 가려지거나 잘려서 팔 하나만 보일 수 있어.
신체 일부만 보여도 사람으로 세어줘. <answer> 태그로 답하기 전에
<thinking> 태그 안에서 이미지의 모든 부분을 단계별로 분석해.` }
실습
  1. 아무 이미지 파일 2~3개를 준비하세요.
  2. imagePart 헬퍼로 이미지 파트를 만들어 "이 이미지들에 공통으로 나타나는 것은?"을 물어보세요.
  3. 같은 요청을 라벨 없이 / "이미지 N:" 라벨과 함께 각각 보내고 결과를 비교해 보세요.
  4. 도전: 프레젠테이션 슬라이드 사진을 받아 텍스트로 전사(transcribe)해 보세요.
