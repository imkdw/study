다중 도구 챗봇 만들기

가짜 주문 DB에 연결된 고객 지원 봇을 대화 루프로 완성합니다.

원본: 06_chatbot_with_multiple_tools.ipynb

레슨

최종 프로젝트: 고객의 주문 조회/취소를 도와주는 지원 챗봇. 여러 도구를 등록하고 대화형 루프를 구현합니다.

1. 가짜 데이터베이스

class FakeDatabase {
  customers = [
    { id: "1213210", name: "John Doe", email: "john@gmail.com", phone: "123-456-7890", username: "johndoe" },
    { id: "2837622", name: "Priya Patel", email: "priya@candy.com", phone: "987-654-3210", username: "priya123" },
    // ...
  ];
  orders = [
    { id: "24601", customerId: "1213210", product: "Wireless Headphones", price: 79.99, status: "Shipped" },
    { id: "13579", customerId: "1213210", product: "Smartphone Case", price: 19.99, status: "Processing" },
    // ...
  ];

  getUser(key: string, value: string) {
    if (key !== "email" && key !== "phone" && key !== "username") {
      return `Invalid key: ${key}`;
    }
    return this.customers.find((c) => c[key] === value)
      ?? `Couldn't find a user with ${key} of ${value}`;
  }

  getOrderById(orderId: string) {
    return this.orders.find((o) => o.id === orderId) ?? null;
  }

  getCustomerOrders(customerId: string) {
    return this.orders.filter((o) => o.customerId === customerId);
  }

  cancelOrder(orderId: string) {
    const order = this.getOrderById(orderId);
    if (!order) return "Can't find that order!";
    if (order.status !== "Processing") return "Order has already shipped. Can't cancel it.";
    order.status = "Cancelled";
    return "Cancelled the order";
  }
}

const db = new FakeDatabase();

3. 도구 디스패처

함수 이름을 실제 DB 메서드로 연결합니다:

function runTool(name: string, args: Record<string, unknown>) {
  switch (name) {
    case "getUser":
      return typeof args.key === "string" && typeof args.value === "string"
        ? db.getUser(args.key, args.value)
        : "Invalid arguments";
    case "getOrderById":
      return typeof args.orderId === "string"
        ? db.getOrderById(args.orderId) ?? "Order not found"
        : "Invalid orderId";
    case "getCustomerOrders":
      return typeof args.customerId === "string"
        ? db.getCustomerOrders(args.customerId)
        : "Invalid customerId";
    case "cancelOrder":
      return typeof args.orderId === "string"
        ? db.cancelOrder(args.orderId)
        : "Invalid orderId";
    default:
      return `Unknown tool: ${name}`;
  }
}

4. 대화 루프

functionCall이 올 때마다 실행 → 결과 추가 → 재요청을 반복합니다. Gemini의 chat 세션이 이력을 관리해 줍니다:

const chat = ai.chats.create({
  model: "gemini-3.6-flash",
  config: {
    tools,
    systemInstruction: `You are a customer support chatbot for an online retailer.
Use the provided tools to look up customers and orders. Confirm order details
with the user before cancelling. If a tool returns an error, explain it kindly.`,
  },
});

async function sendMessage(userMessage: string) {
  let response = await chat.sendMessage({ message: userMessage });

  // functionCall이 없을 때까지 도구 실행 루프
  while (response.functionCalls?.length) {
    const functionResponseParts = await Promise.all(
      response.functionCalls.map(async (call) => ({
        functionResponse: {
          name: call.name ?? "",
          response: { result: runTool(call.name ?? "", call.args ?? {}) },
        },
      })),
    );
    response = await chat.sendMessage({ message: functionResponseParts });
  }
  return response.text;
}

5. 대화 예시

await sendMessage("Hi, I'm johndoe. Can you check my orders?");
// 봇: getUser → getCustomerOrders 호출 → "주문 2건이 있습니다..."

await sendMessage("Cancel order 13579 please");
// 봇: cancelOrder 호출 → "Processing 상태라 취소했습니다"

await sendMessage("What about order 24601?");
// 봇: getOrderById → "이미 배송돼서 취소 불가"를 설명

프롬프트 개선 포인트

  • 확인 절차: 취소 전 주문 상세를 사용자에게 확인하라고 system instruction에 명시
  • 범위 제한: 도구와 무관한 요청(농담, 코드 작성)은 거절 — 코스 3-5 패턴 재활용
  • 에러 응답 처리: 도구가 에러 문자열을 반환하면 사용자 친화적으로 설명
실무 고려사항

실제 프로덕션에서는: 도구 실행 결과의 유효성 검증, 사용자 확인 단계 (취소 같은 파괴적 작업), 권한 체크(본인 주문만 조회), 도구 호출 로깅이 필요합니다. @google/genai의 AFC를 쓰면 이 루프가 자동화되지만, 수동 루프의 제어권이 필요한 경우도 많습니다.

연습 6.1 — 인터랙티브 챗봇

readline으로 사용자 입력을 받는 대화형 스크립트를 완성해 보세요. "quit" 입력 시 종료하고, 매 턴 sendMessage를 호출합니다.

골격 
import * as readline from "node:readline";

const rl = readline.createInterface({ input: process.stdin, output: process.stdout });
const ask = (q: string) => new Promise<string>((res) => rl.question(q, res));

while (true) {
  const input = await ask("You: ");
  if (input.toLowerCase() === "quit") break;
  console.log("Bot:", await sendMessage(input));
}
rl.close();
