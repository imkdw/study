도구 선택 제어 (tool choice)

모델이 도구를 쓸지 말지, 어떤 도구를 쓸지를 제어합니다.

원본: 05_tool_choice.ipynb

레슨

Claude의 tool_choice(auto/any/tool/none)에 해당하는 Gemini 설정은 toolConfig.functionCallingConfig.mode입니다.

Claude tool_choiceGemini mode동작
autoAUTO (기본값)모델이 판단 — 도구 호출 또는 텍스트 응답
anyANY반드시 함수 호출 (어느 것이든)
tool (특정 도구)ANY + allowedFunctionNames지정한 함수만 허용
noneNONE함수 호출 금지, 텍스트만

AUTO (기본)

도구를 제공해도 모델이 알아서 판단합니다:

import { FunctionCallingConfigMode } from "@google/genai";

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "What color are emeralds?",   // 계산기 필요 없음
  config: {
    tools: [{ functionDeclarations: [calculatorDeclaration] }],
    // mode 생략 시 AUTO
  },
});
// 보통 functionCalls 없이 텍스트 응답이 옴
프롬프트가 중요하다

AUTO 모드에서도 모델이 불필요하게 도구를 호출할 수 있습니다. 도구의 description에 "언제 쓰는지"를 명확히 적고, 필요하면 system instruction으로 사용 조건을 제한하세요.

ANY — 호출 강제

항상 함수 호출을 반환하게 합니다. 구조화 출력 추출에 유용합니다 (5-3 참고):

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "Multiply 1984135 by 9343116",
  config: {
    tools: [{ functionDeclarations: [calculatorDeclaration] }],
    toolConfig: {
      functionCallingConfig: { mode: FunctionCallingConfigMode.ANY },
    },
  },
});
// 반드시 functionCalls가 채워짐

특정 함수만 허용

여러 도구 중 하나만 강제하려면 allowedFunctionNames를 씁니다:

config: {
  tools: [{ functionDeclarations: [calculatorDecl, getWeatherDecl] }],
  toolConfig: {
    functionCallingConfig: {
      mode: FunctionCallingConfigMode.ANY,
      allowedFunctionNames: ["calculator"],   // calculator만 호출 가능
    },
  },
}

NONE — 도구 비활성화

도구 정의는 유지하되 이 요청에서는 호출을 막습니다:

toolConfig: {
  functionCallingConfig: { mode: FunctionCallingConfigMode.NONE },
}

예: 대화 이력에 도구 맥락이 필요하지만 이번 응답은 텍스트만 받고 싶을 때.

선택 가이드
  • AUTO: 일반 챗봇, 도구가 "필요하면" 쓰이는 경우
  • ANY: 구조화 출력 추출, 반드시 행동이 필요한 단계
  • NONE: 도구 사용이 부적절한 요청 (요약만 필요한 경우 등)
