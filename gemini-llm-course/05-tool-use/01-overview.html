Tool Use 기초

모델이 외부 함수(function calling)를 요청하는 구조를 이해합니다.

원본: 01_tool_use_overview.ipynb

레슨

Tool use(Gemini에서는 function calling)는 모델이 텍스트 응답 대신 "이 함수를 이 인자로 호출해줘"라는 구조화된 요청을 출력하는 기능입니다.

가장 중요한 사실

모델은 코드를 직접 실행하지 않습니다. 모델이 함수 호출을 요청하면, 실제 실행과 결과 반환은 우리 코드의 몫입니다. 서버 측 내장 도구도 없습니다 — 모든 도구는 매 요청마다 우리가 명시적으로 제공합니다.

왜 중요한가

  • 모델의 지식 한계 극복 (실시간 주가, 날씨, DB 조회)
  • 계산/검증 등 모델이 약한 작업을 실제 코드에 위임
  • 구조화된 출력(JSON) 강제
  • 외부 시스템 조작 (주문 취소, 이메일 발송 등)

Tool use의 동작 흐름

  1. 도구와 프롬프트 제공 (요청): 도구 이름, 설명, 입력 스키마를 정의해 모델에 알려주고, 도구가 필요할 수 있는 사용자 프롬프트를 보냅니다.
  2. 모델이 도구 사용 결정 (응답): 프롬프트를 보고 도구가 도움되는지 판단하고, 어떤 도구를 어떤 인자로 쓸지 담은 functionCall을 반환합니다.
  3. 인자 추출, 코드 실행, 결과 반환 (요청): 클라이언트가 실제 함수를 실행하고 functionResponse로 결과를 돌려줍니다.
  4. 결과를 바탕으로 최종 응답 생성 (응답): 모델이 도구 결과를 받아 원래 질문에 대한 최종 답을 만듭니다.

3-4단계는 선택 사항입니다. 도구 호출 자체가 목적(예: 구조화 출력)이라면 결과를 돌려주지 않아도 됩니다.

시나리오: 주가 조회

"$500으로 General Motors 주식을 몇 주 살 수 있어?"라는 질문에 모델은 실시간 주가를 모릅니다. getStockPrice 도구를 제공합니다.

Step 0: 도구 함수 작성

async function getStockPrice(company: string) {
  // 실제로는 주식 API 호출. 여기선 가짜 응답.
  return { symbol: "GM", price: 43.09 };
}

Step 1: 도구 정의 + 요청

Gemini에서는 functionDeclarations로 도구를 정의합니다:

import { GoogleGenAI, Type } from "@google/genai";

const ai = new GoogleGenAI({});

const getStockPriceDeclaration = {
  name: "getStockPrice",
  description: "Retrieves the current stock price for a given company",
  parameters: {
    type: Type.OBJECT,
    properties: {
      company: {
        type: Type.STRING,
        description: "The company name to fetch stock data for",
      },
    },
    required: ["company"],
  },
};

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: "How many shares of General Motors can I buy with $500?",
  config: {
    tools: [{ functionDeclarations: [getStockPriceDeclaration] }],
  },
});

Step 2: 모델의 함수 호출 요청

// response.functionCalls:
// [{ name: "getStockPrice", args: { company: "General Motors" } }]
const call = response.functionCalls?.[0];

Step 3: 함수 실행 + 결과 반환

const result = await getStockPrice(call.args.company);

const finalResponse = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: [
    { role: "user", parts: [{ text: "How many shares of General Motors can I buy with $500?" }] },
    response.candidates?.[0]?.content,              // 모델의 functionCall 턴
    {
      role: "user",
      parts: [{
        functionResponse: {
          name: "getStockPrice",
          response: { result },
        },
      }],
    },
  ],
  config: { tools: [{ functionDeclarations: [getStockPriceDeclaration] }] },
});

Step 4: 최종 응답

"현재 주가 $43.09 기준으로 $500이면 General Motors 주식 약 11주를 살 수 있습니다."
