완성된 tool use 워크플로

검색 도구를 붙여 호출 요청 → 실행 → 결과 반환 → 최종 답변까지 전체 루프를 만듭니다.

원본: 04_complete_workflow.ipynb

레슨

목표: "어떤 주제든 물어보면 위키피디아를 검색해 답하는" 봇. 원본은 Wikipedia API를 쓰지만, 여기선 구조만 같고 검색 함수는 목업합니다.

1. 도구 함수 정의

async function searchWikipedia(topic: string) {
  // 실제로는 Wikipedia REST API 호출.
  // 실습용 목업:
  const articles: Record<string, string> = {
    "moon landing": "The Apollo 11 mission landed humans on the Moon in 1969...",
  };
  return articles[topic.toLowerCase()] ?? `No article found for "${topic}"`;
}

2. 도구 선언

const searchWikipediaDeclaration = {
  name: "searchWikipedia",
  description: "Searches Wikipedia for a topic and returns the article text. Use this when you need factual information you may not know.",
  parameters: {
    type: Type.OBJECT,
    properties: {
      topic: { type: Type.STRING, description: "The topic to search on Wikipedia." },
    },
    required: ["topic"],
  },
};

const tools = [{ functionDeclarations: [searchWikipediaDeclaration] }];

3-4. 요청 → functionCall 응답

const userQuestion = "Tell me about the moon landing";

const firstResponse = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: userQuestion,
  config: { tools },
});

const call = firstResponse.functionCalls?.[0];
// { name: "searchWikipedia", args: { topic: "moon landing" } }

5. 실행하고 결과 반환

결과를 돌려줄 때 대화 전체를 이어 붙입니다. 모델의 functionCall 턴을 그대로 포함하는 것이 핵심입니다:

const modelTurn = firstResponse.candidates?.[0]?.content;
if (!call || !modelTurn) throw new Error("Expected a function call");

const toolResult =
  call.name === "searchWikipedia" && typeof call.args?.topic === "string"
    ? await searchWikipedia(call.args.topic)
    : "Unknown tool or bad args";

const contents = [
  { role: "user", parts: [{ text: userQuestion }] },
  modelTurn,
  {
    role: "user",
    parts: [{ functionResponse: { name: call.name, response: { result: toolResult } } }],
  },
];

6. 최종 응답 생성

const finalResponse = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents,
  config: { tools },
});
console.log(finalResponse.text);
// 위키 기사 내용을 반영한 답변
Gemini의 자동 function calling

@google/genai SDK는 도구로 실제 JS 함수를 넘기면 자동으로 실행까지 해주는 AFC(automatic function calling)를 지원합니다. 다만 이 코스에서는 흐름 이해를 위해 수동 루프를 유지합니다. 실무에서는 AFC가 보일러플레이트를 크게 줄여 줍니다.

도구가 필요 없는 질문 처리

"안녕?" 같은 질문에는 도구를 안 쓰는 게 맞습니다. 문제는 모델이 도구를 지나치게 쓰고 싶어할 때입니다. 두 가지 완충 장치:

① 프롬프트 보강 — 도구 사용 조건을 system instruction에 명시:

const system = `You are a helpful assistant with access to a Wikipedia search tool.
Only use the searchWikipedia tool when the user's question requires factual
information you may not reliably know. For greetings, opinions, or questions
you can answer confidently, respond directly without using tools.`;

② 응답에서 분기 — functionCall이 없으면 그냥 텍스트로 답합니다:

const res = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: userQuestion,
  config: { tools, systemInstruction: system },
});

const calls = res.functionCalls;
if (!calls || calls.length === 0) {
  console.log(res.text);          // 도구 없이 직접 답변
} else {
  // function call 처리 루프
}
