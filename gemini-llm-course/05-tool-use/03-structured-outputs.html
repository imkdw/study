Tool use로 JSON 강제하기

스키마를 도구로 정의해 구조화된 출력을 얻는 기법, 그리고 Gemini의 더 간단한 대안.

원본: 03_structured_outputs.ipynb

레슨

원본 레슨의 핵심 아이디어: 원하는 JSON 스키마를 "도구"로 정의하고 모델이 그 도구를 호출하게 하면, 결과가 스키마에 맞는 구조화 데이터로 나옵니다. 도구의 args가 곧 원하는 JSON입니다.

Gemini에서는 두 가지 방법

① 원본처럼 function calling 강제(mode: ANY)로 스키마 준수 args를 얻거나, ② Gemini 네이티브인 responseMimeType: "application/json" + responseSchema를 씁니다. ②가 더 직접적이고 권장되지만, ①을 배우면 function calling의 활용 폭을 이해할 수 있습니다. 둘 다 보여드립니다.

예시: 감정 분석

리뷰 텍스트에서 감정과 키워드를 구조화해서 추출합니다. "도구"로 스키마를 정의합니다:

const sentimentAnalysisDeclaration = {
  name: "reportSentiment",
  description: "Reports the sentiment analysis result of a text.",
  parameters: {
    type: Type.OBJECT,
    properties: {
      sentiment: {
        type: Type.STRING,
        enum: ["positive", "negative", "neutral"],
        description: "The overall sentiment of the text.",
      },
      keywords: {
        type: Type.ARRAY,
        items: { type: Type.STRING },
        description: "Key words or phrases that indicate the sentiment.",
      },
    },
    required: ["sentiment", "keywords"],
  },
};

모델이 도구를 선택하지 않을 수도 있으므로 호출을 강제합니다:

import { FunctionCallingConfigMode } from "@google/genai";

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: `Analyze the sentiment of this review:
<review>The food was amazing but the service was terribly slow.</review>`,
  config: {
    tools: [{ functionDeclarations: [sentimentAnalysisDeclaration] }],
    toolConfig: {
      functionCallingConfig: {
        mode: FunctionCallingConfigMode.ANY,           // 반드시 함수 호출
        allowedFunctionNames: ["reportSentiment"],     // 이 함수만
      },
    },
  },
});

const structured = response.functionCalls?.[0]?.args;
// { sentiment: "positive", keywords: ["amazing", "food", "slow service"] }

Gemini 네이티브 대안: responseSchema

도구 호출 없이 같은 결과를 얻는 더 간단한 방법입니다:

const response = await ai.models.generateContent({
  model: "gemini-3.6-flash",
  contents: `Analyze the sentiment of this review:
<review>The food was amazing but the service was terribly slow.</review>`,
  config: {
    responseMimeType: "application/json",
    responseSchema: {
      type: Type.OBJECT,
      properties: {
        sentiment: { type: Type.STRING, enum: ["positive", "negative", "neutral"] },
        keywords: { type: Type.ARRAY, items: { type: Type.STRING } },
      },
      required: ["sentiment", "keywords"],
    },
  },
});

const data = JSON.parse(response.text ?? "{}");
언제 어느 쪽?

responseSchema: 출력이 항상 JSON 하나일 때 — 더 간단하고 안정적. function calling 강제: "JSON 추출"이 여러 가능한 행동 중 하나이거나, 스키마 준수 호출을 대화 흐름에 섞고 싶을 때.
