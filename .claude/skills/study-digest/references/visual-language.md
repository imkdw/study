# 시각화 판단 기준

## 0. 대원칙

> 스크린샷은 **정보**지 **그림**이 아니다.
> 이미지를 Read 로 열어 "이 캡처가 전달하려는 정보 한 줄"을 먼저 적고, 그 정보를 가장 잘 나르는 형식을 고른다.

이미지를 못 열었거나 판독이 안 되면 그 자리를 비우고 QA 에 남긴다. 지어내지 않는다.

## 1. 이미지 → 재현 형식 매핑

| 캡처 내용 | 재현 형식 | 비고 |
| --- | --- | --- |
| IDE 호버 툴팁 (추론된 타입) | `.ide` + `.hovercard` | 시그니처를 텍스트로 그대로 옮긴다 |
| IDE 자동완성 목록 | `.ide` + `.hovercard` 여러 줄 | 항목이 많으면 표로 |
| 빨간 물결 밑줄 + 에러 | 코드 블록 + `.squiggly` + `.callout.danger` | 에러 전문을 danger 에 |
| 터미널 출력 | 코드 블록 (`language-bash`), `code-file` 에 `terminal` | |
| 아키텍처 / 데이터 흐름 | mermaid `flowchart` | |
| 시간 순서, 호출 순서 | mermaid `sequenceDiagram` | |
| 상속 / 계층 구조 | mermaid `flowchart TB` 또는 `classDiagram` | |
| 상태 전이 | mermaid `stateDiagram-v2` | |
| 집합 포함 / 교집합 | 인라인 SVG 벤 다이어그램 | |
| 수치 비교, 벤치마크 | `<table>` 또는 SVG 막대 | 데이터가 3개 이하면 표 |
| 표/매트릭스 캡처 | `<table>` | |
| 순수 코드 캡처 | 코드 블록 | 캡처 속 주석까지 옮긴다 |
| 손그림 개념도 | mermaid 또는 SVG 재구성 | 낙서를 정돈된 도해로 |

## 2. 이미지가 없어도 그려야 할 때

노트가 글로만 설명하지만 그림이 훨씬 빠른 경우가 있다. 아래 신호가 보이면 다이어그램을 추가한다.

- "A 는 B 의 부분집합", "A 가 B 를 포함한다" → 벤 다이어그램
- "1) ... 2) ... 3) ..." 로 이어지는 처리 순서 → `ol.steps` 또는 sequenceDiagram
- "X 하면 Y 가 되고, 아니면 Z" → flowchart 분기
- 서로 대응되는 축이 두 개(예: 옵션 × 동작) → 표
- 계층/상속이 3단 이상 → flowchart TB

다이어그램은 **아이템당 최대 2개**. 글로 충분한 걸 굳이 그리면 밀도만 떨어진다.

## 3. 다이어그램 품질 기준

- 노드 5~9개. 그보다 많으면 둘로 쪼갠다.
- 라벨은 명사구로 짧게. 문장을 통째로 넣지 않는다.
- 화살표에 라벨을 달아 **관계의 종류**를 밝힌다 (`-->|"할당 가능"|`).
- 캡션(`figure-cap`)에 **이 그림에서 읽어야 할 한 줄**을 굵게 적는다. 캡션 없는 그림은 넣지 않는다.
- 색으로만 구분하지 않는다. 라벨/모양도 같이 다르게 한다.

## 4. 벤 다이어그램 좌표 참고값

`viewBox="0 0 460 220"` 기준

| 관계 | 배치 |
| --- | --- |
| 부분집합 (A ⊂ B) | 큰 원 `cx=230 cy=110 r=95`, 작은 원 `cx=230 cy=130 r=48` |
| 교집합 | `cx=185/275, cy=110, r=80` |
| 서로소 | `cx=140/320, cy=110, r=68` |
| 3중 포함 | r=100 / r=68 / r=38, cy 를 각각 105 / 120 / 132 |

라벨은 `<text class="dg-text dg-mono" font-size="13" text-anchor="middle">`, 부연은 `dg-text-sub` + `font-size="11"`.

## 5. 색 사용 규칙

| 의미 | 변수 |
| --- | --- |
| 기본 강조 / 정상 흐름 | `var(--accent)` |
| 에러 / 금지 | `var(--red)` |
| 성공 / 권장 | `var(--green)` |
| 주의 | `var(--yellow)` |
| 최신 변경 | `var(--purple)` |
| 배경 / 보조면 | `var(--surface)` `var(--surface-alt)` |

SVG 에서는 위 값을 직접 쓰지 말고 `class="venn-a"` 처럼 정의된 클래스를 쓴다.
정 필요하면 `fill="var(--accent)"` 형태로 변수를 참조한다.
