# /digest

`study-digest` 스킬을 실행한다.

**대상**: `$1` (없으면 현재 작업 중인 스터디 폴더를 추론하고, 애매하면 후보를 보여준 뒤 고르게 한다)
**옵션**: `$ARGUMENTS`

## 순서

1. `Skill` 툴로 `study-digest` 를 불러 규약을 적재한다.
2. 대상 폴더를 스캔해 **분석 요약**을 먼저 보고한다 — 노트 수 / 분량 / 챕터 구성 / 이미지 수와 종류 / 코드 언어 분포.
3. `.digest/meta.json` 목차를 확정한다.
4. 이미지를 전부 Read 로 판독한 뒤 재현 형식을 정한다.
5. 챕터 단위로 `partials/*.html` 을 쓰고, 한 챕터가 끝날 때마다 어셈블해 중간 결과를 확인한다.
6. 검증(`--no-verify` 가 없으면)과 QA 체크리스트를 돌린다.
7. 산출물 경로, 커버된 아이템 수, 교정/보강 목록, 확인 못 한 항목을 보고한다.

## 규칙

- 원본 마크다운과 이미지는 **수정/삭제하지 않는다**. 읽기만 한다.
- 산출물은 HTML **한 파일**. 기본 경로는 `<대상 폴더>/<폴더명>.html`.
- 중간에 멈추지 않는다. 챕터를 나눠 끝까지 완성한 뒤 한 번에 보고한다.
- 진행 중 발견한 원문 오류는 고치되, 무엇을 고쳤는지 마지막 보고에 모아 알린다.
